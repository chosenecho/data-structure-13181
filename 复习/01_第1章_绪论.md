## 数据、数据元素、数据项

这三者是包含关系，不是并列，也不是一对一。

数据是最大的那个，指所有能输入计算机并被处理的符号的集合。数据元素是集合里的一个个体，是作为整体处理的单位。数据项是元素里不可再分的最小单位。

拿学生表举例：整张学生表是数据，其中一行"张三、2023001、男、85"是一个数据元素，"姓名""学号"这些字段是数据项。

背两句话就够：数据项是数据的最小单位，数据元素是数据的基本单位。

选择题里常出现"数据项由若干数据元素组成"，这是反的，一眼就能排除。

## 数据结构的三个组成

数据结构 = 逻辑结构 + 存储结构 + 数据的运算。

只讲逻辑结构那只是数学模型，配上存储结构和操作才成为数据结构。2025 年那道填空考的就是这个思路：`LinearList` 里那些函数，一部分返回值表示操作是否已正确执行，另一部分表示操作的结果。这道题如果不理解"操作为什么要单独成一维"，很容易填错。

### 逻辑结构四类

| 逻辑结构 | 元素间关系 | 长什么样 | 例子 |
|---|---|---|---|
| 集合 | 除同属一个集合外没别的关系 | 一堆散点 | 班级名单 |
| 线性结构 | 一对一，唯一前驱唯一后继 | 一条链 | 线性表、栈、队列、串 |
| 树结构 | 一对多，有层次 | 倒挂的树 | 文件目录、家族谱 |
| 图结构 | 多对多，网状 | 一张网 | 交通网、社交关系 |

非线性结构就是集合、树、图三家。树是图的特例，因为树连通且无回路。

### 存储结构四种

| 方法 | 做法 | 好处 | 代价 | 用在哪 |
|---|---|---|---|---|
| 顺序存储 | 连续单元，逻辑相邻即物理相邻 | 能随机访问，O(1) 定位，无指针开销 | 插删要搬元素，容量固定 | 顺序表、顺序栈、数组、堆 |
| 链式存储 | 任意单元，靠指针表示关系 | 插删 O(1)，容量可长可缩 | 只能顺序访问，每结点多指针 | 单链表、二叉树、邻接表 |
| 索引存储 | 数据加一张索引表 | 按关键字查得快 | 索引表占空间，插删要维护 | 索引顺序查找、数据库索引 |
| 散列存储 | 关键字经哈希函数直接算地址 | 理想情况 O(1) | 有冲突，要处理 | 哈希表 |

四个字记住：顺、链、索、散。

逻辑结构和存储结构的关系，三句话：

逻辑结构是问题的数学模型，跟计算机无关；存储结构是逻辑结构在计算机里的表示。一种逻辑结构可以有多种存储结构，比如线性表能做成顺序表、单链表、静态链表。存储结构不同，同一个操作的实现和效率就不同。按下标取第 i 个元素，顺序表 O(1)，链表 O(n)。这也是为什么考卷总爱问"为什么选顺序表不选链表"。

## 抽象数据类型

ADT 由三部分组成：数据对象 D、D 上的关系 S、D 上的基本操作集 P。

三个特征：抽象性、信息隐藏、与实现无关。它只关心"做什么"，不关心"怎么做"。

C 语言里用 `typedef struct` 加函数原型来模拟 ADT，教材那个 `ADT LinearList` 就是这么写的。

解答题要写全，格式是：

```
ADT 名字 {
    数据部分：
        D { ... }              // 数据对象及逻辑关系
    操作部分：
        操作1(参数表);          // 前置条件、功能、返回值含义
        操作2(参数表);
        ...
} ADT 名字
```

数据部分和操作部分两块都写，缺一块就扣分。

## 算法和五个特性

算法是对特定问题求解步骤的描述，是指令的有限序列。

| 特性 | 含义 | 反例 |
|---|---|---|
| 有穷性 | 有限步后终止，每步也在有限时间内完成 | `while(1)` 死循环不是算法 |
| 确定性 | 每步含义唯一无二义，相同输入得相同输出 | "取一个较大的数"不是算法 |
| 可行性 | 每步都能有效执行 | "求 π 的精确值"不可行 |
| 输入 | 零个或多个 | 可以没有输入 |
| 输出 | 一个或多个 | 没有输出的程序没意义 |

三个容易错的地方。

算法不等于程序。程序可以不考虑有穷性（操作系统主循环、服务器进程），算法必须有穷。算法是抽象的，程序是具体的实现。可以说算法是程序的灵魂。

输入可以是零个，输出不能是零个。这一点常被记反。

有穷性不只要求"最终会停"，还要求每一步也在有限时间内完成。一个跑三步但每步要等无限过程的算法，不合规。

## 问题规模与增长函数

问题规模指输入量的大小。排序看元素个数 n，矩阵乘法看阶数 n，图算法看顶点数加边数。

增长函数描述执行时间随 n 增长的趋势。

大 O 表示法：存在正常数 c 和 n₀，使 n ≥ n₀ 时 `T(n) ≤ c·f(n)`，记作 `T(n) = O(f(n))`。它给的是上界，通常对应最坏情况。

写法规则很简单：只留最高阶项，去掉系数。`3n² + 100n + 7 = O(n²)`。

量级从小到大：

```
O(1) < O(log₂n) < O(n) < O(n log₂n) < O(n²) < O(n³) < O(2ⁿ) < O(n!)
```

常数、对数、线性、线性对数、平方、立方、指数、阶乘。

## 时间复杂度怎么数

方法就一个：找到执行次数最多的那条语句，数它跑了多少次，用 n 表示。

### 六个常见形态

| 代码长相 | 复杂度 | 怎么看 |
|---|---|---|
| `x = a + b;` | O(1) | 没循环 |
| `for(i=1;i<=n;i++) s++;` | O(n) | 一层 |
| 两层都到 n | O(n²) | 两层 |
| `for(i=1;i<=n;i++) for(j=1;j<=i;j++)` | O(n²) | 内层跑 1+2+…+n，还是平方 |
| `for(i=1;i<=n;i*=2)` | O(log₂n) | 步长是乘除 |
| 外层 n 层，内层 `j*=2` | O(n log n) | 相乘 |

### 四个坑

第一个，`i *= 2` 和 `i /= 2` 是对数。执行 k 次满足 2^k ≈ n，k = log₂n。看到乘除就往对数想。

第二个，两层循环不等于平方，要看内层上限是什么。

```c
for(i=1;i<=n;i++)
    for(j=1;j<=n;j+=i)   // 内层次数约 n/i
        s++;
```
总次数约 n(1 + 1/2 + 1/3 + … + 1/n) = n·H(n) ≈ n·ln n，是 O(n log n)。调和级数这个结论值得记住。

第三个，循环条件里带 i*i 或 sqrt 的。

```c
for(i=0; i*i<n; i++) s++;   // 跑 √n 次
```

第四个，递归要用递推式。`T(n)=T(n-1)+O(1)` 是 O(n)，`T(n)=2T(n/2)+O(n)` 是 O(n log n)，`T(n)=T(n/2)+O(1)` 是 O(log n)。归并排序和快排平均都属于中间那个形状。

### 三种情况

最好情况是理想输入下的复杂度，最坏情况是最不利输入，平均情况按概率加权。

考试默认问最坏或平均，除非题目明说"最好"。

## 空间复杂度

指算法运行所需的辅助存储空间，不含输入数据本身。

原地工作的算法辅助空间是常数，S(n) = O(1)。冒泡、插入、选择、堆排序都算。快排严格说不算，因为有递归栈 O(log n)。

递归的空间开销等于递归深度。求二叉树高度的算法时间 O(n)、空间 O(h)，h 是树高。

几个对照：归并排序 S(n)=O(n)，因为要辅助数组；快排 S(n)=O(log n)，递归栈；基数排序 S(n)=O(n+r)。

## 六种算法策略

只需要认得出，不用会实现。

| 策略 | 核心 | 特征 | 代表算法 |
|---|---|---|---|
| 递推法 | 由初值用递推公式逐项推 | 自小而大，循环实现 | 斐波那契、杨辉三角 |
| 迭代法 | 用旧值反复算新值直到满足精度 | 不断逼近 | 牛顿迭代、二分法求根 |
| 递归法 | 化为规模更小的同类子问题 | 有出口有递归体，用系统栈 | 阶乘、汉诺塔、树遍历 |
| 贪心法 | 每步取当前最优，不回头 | 局部最优得全局最优，需可证 | Prim、Kruskal、Dijkstra、哈夫曼 |
| 分治法 | 分解、分别求解、合并 | 子问题独立，规模减半 | 归并、快排、折半查找 |
| 动态规划 | 分阶段决策，保存子问题结果 | 最优子结构加重叠子问题 | Floyd、0-1 背包 |

最常被问的是分治和动态规划的区别。分治的子问题相互独立、不重复，快排的左右两半互不影响。动态规划的子问题重叠，所以要记表，否则退化成指数级。

贪心和动态规划的区别在于，贪心做了选择就不改；动态规划保留所有子问题的解，最后再决策。

## 考前十分钟看这些

1. 数据包含数据元素，数据元素包含数据项。数据项最小，数据元素基本。
2. 数据结构 = 逻辑结构 + 存储结构 + 运算。
3. 逻辑结构四类：集合、线性、树、图。非线性是集合加树加图。
4. 存储方法四种：顺序、链式、索引、散列。
5. 逻辑结构独立于计算机，一种逻辑多种存储，存储影响操作效率。
6. ADT 是 D、S、P 三元组，特征是抽象、隐藏、与实现无关。
7. 算法五特性：有穷、确定、可行、输入、输出。
8. 算法不等于程序。算法有穷，程序可无穷。
9. 大 O 只留最高阶、去系数。
10. `i*=2` 是对数。两层独立满循环是平方。`T(n)=2T(n/2)+O(n)` 是 n log n。
11. 空间复杂度只算辅助空间，递归的空间等于递归深度。
12. 六策略：递推、迭代、递归、贪心、分治、动态规划。

### B 组

**B-1 O(log₂n)**
设执行 k 次，i 的值为 2^k，循环条件 2^k ≤ n，所以 k ≤ log₂n，即 k = ⌊log₂n⌋+1。

**B-2 O(n³)**
三层都到 n。

**B-3 O(n²)**
内层执行 n-i+1 次，总次数 n + (n-1) + … + 1 = n(n+1)/2，取最高阶是平方。

**B-4 O(√n)**
s = 1+2+…+i = i(i+1)/2 < n，i 约等于 √(2n)，循环跑 √n 次。这是"while 里累加变量"的经典模型，不是 O(n) 也不是 O(log n)。

**B-5 O(n log n)**
固定 i 时内层约 n/i 次。总次数约 n(1 + 1/2 + … + 1/n) = n·H(n) ≈ n ln n。

**B-6 时间 O(n)，空间 O(n)**
f(n) 递归 n 次，每次 O(1)；递归深度 n，系统栈要 n 层。

**B-7 O(log₂n)**
n → n/2 → n/4 → … → 1，共 log₂n 层。

**B-8**
程序一 O(n)，一层循环。程序二 O(1)，一条赋值语句，没有循环。
程序二更好，既快又省空间。这个对比说明算法设计比硬件优化重要得多，一个数学公式抵掉了一个 n 次循环。

**B-9 错误。**
大 O 描述的是增长趋势的上界，`T(n) = O(n²)` 只说明存在常数 c 和 n₀ 使 n ≥ n₀ 时 T(n) ≤ c·n²，不表示恰好 n² 次。实际执行次数可能是 3n² + 5n，也可能在最好情况下远小于 n²。

**B-10 O(n log n)**
主定理的标准情形：`T(n) = aT(n/b) + f(n)`，a=2，b=2，f(n)=n。因为 `f(n) = Θ(n^{log_b a}) = Θ(n)`，所以 `T(n) = Θ(n log n)`。
归并排序、快排平均都属于这个形状。

### C 组

**C-1**
四类：

集合结构，元素之间除了同属一个集合没有其他关系。例：一批无序的会员编号。

线性结构，元素之间一对一，除首元素外每个元素有且仅有一个直接前驱，除尾元素外有且仅有一个直接后继。例：学生成绩表、编辑器里的字符序列。

树结构，元素之间一对多的层次关系，有且仅有一个根，其余元素有且仅有一个前驱、可有多个后继。例：文件目录树、公司组织架构。

图结构，元素之间多对多的网状关系，任一元素可有多个前驱和多个后继。例：城市公路网、社交网络、任务调度的依赖关系。

**C-2**
四种存储方法：

顺序存储把逻辑相邻的结点放在物理相邻的单元里，逻辑关系由存储位置隐含表示，能随机访问。

链式存储把结点放在任意位置，用指针显式表示逻辑关系，只能顺序访问但插删灵活。

索引存储除了存结点信息，还建一张索引表记录关键字到地址的映射。

散列存储由关键字经哈希函数直接算出存储地址。

选择顺序还是链式，考虑三个因素：

主要操作类型。以随机访问、按下标查询为主选顺序，以插入删除为主选链式。

数据规模能否预估、是否频繁变化。可预估且基本固定选顺序，难以预估、频繁增减选链式。

空间开销。顺序存储无指针域、存储密度高；链式每结点有结构性开销，但对空间的利用更按需。

还有一条可作补充：是否需要有序遍历或折半查找，需要的话只能选顺序。

**C-3**
```
ADT StudentList {
    数据部分：
        D = { s_i | s_i = (学号, 姓名, 性别, 成绩), i = 1..n, n ≥ 0 }
        S = { <s_i, s_(i+1)> | 1 ≤ i < n }   // 线性关系

    操作部分：
        InitList(&L)                    // 构造空的学生成绩表 L
        DestroyList(&L)                 // 销毁表 L，释放空间
        ListEmpty(L)                    // 表空返回 1，否则 0
        ListLength(L)                   // 返回学生记录个数
        GetElem(L, pos, &e)             // 用 e 返回位置 pos 处的记录
        LocateElem(L, key)              // 返回学号为 key 的学生位置
        ListInsert(&L, pos, e)          // 在位置 pos 处插入记录 e
        ListDelete(&L, pos, &e)         // 删除位置 pos 处的记录并用 e 返回
        SortByScore(&L)                 // 按成绩降序排列
        AverageScore(L)                 // 返回全体学生的平均成绩
} ADT StudentList
```
评分看三点：数据部分和操作部分两块都在；操作能覆盖插入、删除、查找、取值、求长这几类；每个操作有一句功能说明。

**C-4**
n = 10 时，A 是 1000，B 是 100×100 = 10000，C 是 3^10 = 59049。A 最少。

n = 1000 时，A 是 10^9，B 是 100×10^6 = 10^8，C 是 3^1000（天文数字）。B 最少。

这组数据说明：n 较小时常数系数起主导作用，低阶算法可能因为系数大而表现更差（B 的系数 100 拖累了它在 n=10 时的成绩）。n 足够大时增长量级起主导作用，系数的影响被淹没。n² 终将超过 n³，而 3ⁿ 终将压倒一切多项式。

结论是算法分析先看量级，再看系数。n 较大时量级低者必胜。

**D-5**
（1）有穷性：算法必须在执行有限个步骤之后终止，且每一步都在有限时间内完成。
反例：`while (1) { x++; }` 永不终止，不是算法。另一个反例是步骤有限但每步要等一个无限过程（比如"输出 π 的全部小数位"），同样违背有穷性。

确定性：每条指令必须有确切含义，无二义性；相同输入只能得到相同输出。
反例："若 x 较大则输出 x"，"较大"含义不唯一。另一个反例是用了未初始化的随机变量，相同输入可能得不同输出。

（2）不违背。算法的输入特性只要求"零个或多个输入"，也就是可以没有输入，并不是要求"必须定义输入"。比如"输出一行固定星号"的算法不需要任何输入，仍是合法算法。对比之下，输出必须至少有一个，否则算法没有意义。
