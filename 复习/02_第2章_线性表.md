## 定义和术语

线性表是 n（n ≥ 0）个类型相同的数据元素的有限序列，写作 `(a₁, a₂, …, aₙ)`。

三个词值得停一下。有限，说明它是"表"不是"流"。有序，元素有先后。同类型，所以它是"表"不是"元组"。逻辑上是一对一关系。

术语这一堆，填空爱考：

| 术语 | 含义 | 拿 a₁,a₂,a₃,a₄ 举例 |
|---|---|---|
| 表长 n | 元素个数 | 4 |
| 表头元素 | a₁ | a₁ |
| 表尾元素 | aₙ | a₄ |
| 直接前驱 | aᵢ₋₁，唯一 | a₃ 的直接前驱是 a₂ |
| 直接后继 | aᵢ₊₁，唯一 | a₃ 的直接后继是 a₄ |
| 前驱 | a₁ 到 aᵢ₋₁，可能多个 | a₃ 的前驱是 a₁ 和 a₂ |
| 后继 | aᵢ₊₁ 到 aₙ | a₃ 的后继是 a₄ |
| 有序表 | 按关键字递增或递减 | (1,3,5,7) |
| 无序表 | 无固定次序 | (3,1,7,5) |

直接前驱和直接后继只有一个，前驱和后继可能有好几个。这是选择题的常客。

## 抽象数据类型

```
ADT LinearList {
    数据部分：
        D = { a_i | a_i ∈ ElemSet, i = 1..n, n ≥ 0 }
        S = { <a_(i-1), a_i> | 2 ≤ i ≤ n }
    操作部分：
        InitList(&L)                    // 初始化，构造空表
        DestroyList(&L)                 // 销毁表，释放空间
        ClearList(&L)                   // 表置空（长度变 0，但表还在）
        ListEmpty(L)                    // 判空，空返回 1
        ListFull(L)                     // 判满，满返回 1（顺序表才有意义）
        ListLength(L)                   // 返回表长
        GetElem(L, pos, &x)             // 取位置 pos 处的元素，用 x 返回
        SetElem(&L, pos, x)             // 修改位置 pos 处的元素
        LocateElem(L, x)                // 返回 x 第一次出现的位置
        ListInsert(&L, pos, x)          // 在 pos 处插入 x，表长加一
        ListDelete(&L, pos, &x)         // 删除 pos 处元素，用 x 返回，表长减一
} ADT LinearList
```

2025 年真题第 13 题就在这上面做文章：`LinearList` 中定义的函数返回值，一部分表示的是操作的＿＿，另一部分表示函数是否已正确执行。答案是"结果"。

要理解为什么这么设计。看 `int getValue(LinearList *L, Position pos, ELEMType *x)` 这个原型：返回的 int 只是状态码，0 或 1 或 -1，告诉调用者"执行成功没有"；真正的数据通过 `*x` 这个输出参数带回来。教材一直是这个风格，理解了这个，那道题不用想。

位置的约定有两种，考试要先看题目给的循环初值和边界条件再判断。教材常用从 0 开始，有效位置是 `0 .. n-1`，插入位置的有效范围是 `0 .. n`（因为可以插在末尾）。有些实现从 1 开始，有效位置 `1 .. n`。

## 顺序表

用一组地址连续的单元依次存元素，逻辑相邻就是物理相邻。

```c
#define maxSize 100
typedef int ELEMType;
typedef struct {
    ELEMType elem[maxSize];   // 下标 0..maxSize-1
    int len;                  // 当前表长
} SeqList;
```

### 地址计算

```
LOC(aᵢ) = LOC(a₀) + i × L
```

`LOC(a₀)` 是基地址，`L` 是每个元素占的单元数，`i` 是从 0 开始的下标。

随机访问的意思就是：给个下标，用常数时间算出地址，直接取出来，O(1)。这是顺序表独有的能力，链表做不到。

### 表空表满

len 存元素个数时，表空是 `len == 0`，表满是 `len == maxSize`。

也有教材让 len 存最后一个元素的下标，那空的条件就变成 `len == -1`。看代码风格判断。

### 插入

```c
// 在位置 pos 处插入 x，pos 的有效范围 0..L->len
int insertList(SeqList *L, int pos, ELEMType x) {
    int i;
    if (L->len == maxSize) return 0;        // ① 判满
    if (pos < 0 || pos > L->len) return -1; // ② 判位置合法
    for (i = L->len; i > pos; i--)          // ③ 从表尾到 pos，依次后移
        L->elem[i] = L->elem[i - 1];
    L->elem[pos] = x;                       // ④ 放入
    L->len++;                                // ⑤ 表长加一
    return 1;
}
```

顺序不能乱：判满、判位置、后移、赋值、加长度。

移动次数这块常考解答题。插入位置有 n+1 个（0 到 n）。在位置 i 插入要移动 `n - i` 个元素。等概率下平均移动 (1/(n+1))·Σ(n-i) = n/2。时间复杂度 O(n)。

插在第 i 个位置，移后面 n-i 个；平均移一半，也就是 n/2。

### 删除

```c
int removeList(SeqList *L, int pos, ELEMType *x) {
    int i;
    if (L->len == 0) return 0;              // ① 判空
    if (pos < 0 || pos >= L->len) return -1; // ② 判位置（注意是 >= len）
    *x = L->elem[pos];                       // ③ 保存被删元素
    for (i = pos + 1; i < L->len; i++)       // ④ 从 pos+1 到表尾依次前移
        L->elem[i - 1] = L->elem[i];
    L->len--;                                 // ⑤ 表长减一
    return 1;
}
```

插入和删除的边界条件最容易搞混：

| | 判满还是判空 | 位置合法范围 | 循环方向 | 循环变量起点 |
|---|---|---|---|---|
| 插入 | `len == maxSize` | `0 ≤ pos ≤ len` | 从后往前 | `i = len` |
| 删除 | `len == 0` | `0 ≤ pos < len` | 从前往后 | `i = pos+1` |

插入的 pos 可以是 len，因为插在末尾合法。删除的 pos 不能是 len，因为位置 len 上没有元素。

删除位置有 n 个（0 到 n-1）。删位置 i 要移动 `n-1-i` 个元素，等概率平均 (n-1)/2。时间复杂度 O(n)。

### 各操作代价

| 操作 | 时间 | 说明 |
|---|---|---|
| 取第 i 个元素 | O(1) | 随机访问，顺序表的最大优势 |
| 修改第 i 个元素 | O(1) | 同上 |
| 求表长 | O(1) | 直接读 len |
| 判空判满 | O(1) | 比个数 |
| 按值查找 | O(n) | 无序表只能顺序扫 |
| 插入 | O(n) | 平均移 n/2 个 |
| 删除 | O(n) | 平均移 (n-1)/2 个 |
| 输出全部 | O(n) | 遍历 |

## 单链表

用一组任意的单元存元素，每个结点除数据域外还有指针域，靠指针表示逻辑相邻。

```c
typedef int ELEMType;
typedef struct node {
    ELEMType data;      // 数据域
    struct node *next;  // 指针域，指向直接后继
} LinkNode;
typedef LinkNode *LinkList;
```

### 五个"头"别搞混

| 概念 | 指向什么 | 存不存数据 |
|---|---|---|
| 头指针 head | 链表的第一个结点 | 不存，它只是个指针变量 |
| 头结点 | 附加在首结点前 | 不存有效数据，可以存表长之类的辅助信息 |
| 首结点 | 第一个真正放数据的结点 | 存 |
| 表尾结点 | 最后一个结点 | 存，`next == NULL` |
| 空表 | 有头结点时 `head->next == NULL`；无头结点时 `head == NULL` | — |

### 头结点有什么用

解答题问过，答三条。

统一空表和非空表的处理。没有头结点时，空表是 `head == NULL`，插入第一个结点要修改头指针本身，这是个特例。有了头结点，不管表空不空，`head->next` 始终表示首结点。

统一首结点和其他位置的插入删除逻辑。在第一个位置插入或删除时，不用单独判断"是不是在改头指针"。

便于在表头操作，头插是 O(1)。

拿无头结点的情况对照一下更清楚：在第一个位置插入，必须传 `LinkList*` 二级指针才能修改 head；有头结点后，所有位置都变成"在某个结点之后插入"，代码一份就够。

### 四个基本操作

按位置查找：
```c
LinkNode *getNode(LinkList head, int pos) {
    LinkNode *p = head->next;          // 从头结点的后继开始，这是第 1 个真元素
    int j = 1;
    while (p != NULL && j < pos) { p = p->next; j++; }
    return (j == pos) ? p : NULL;
}
```
O(n)，只能顺序走。

插入：
```c
int insertList(LinkList head, int pos, ELEMType x) {
    LinkNode *p = head;
    int j = 0;
    while (p != NULL && j < pos - 1) { p = p->next; j++; }  // 找 pos 的前驱
    if (p == NULL) return 0;
    LinkNode *s = (LinkNode *)malloc(sizeof(LinkNode));
    s->data = x;
    s->next = p->next;      // 先接后继
    p->next = s;            // 再改前驱指针
    return 1;
}
```
这两句顺序绝对不能反。先改 `p->next` 的话，p 原来的后继就丢了，链表断成两截。

时间上，找位置 O(n) 加插入 O(1)，整体 O(n)。如果已知前驱指针，插入就是 O(1)。

删除：
```c
int removeList(LinkList head, int pos, ELEMType *x) {
    LinkNode *p = head, *q;
    int j = 0;
    while (p->next != NULL && j < pos - 1) { p = p->next; j++; }
    if (p->next == NULL) return 0;
    q = p->next;
    *x = q->data;
    p->next = q->next;      // 跨过 q
    free(q);
    return 1;
}
```

头插法建表：
```c
void createHead(LinkList head, int a[], int n) {
    int i;
    for (i = 0; i < n; i++) {
        LinkNode *s = (LinkNode *)malloc(sizeof(LinkNode));
        s->data = a[i];
        s->next = head->next;
        head->next = s;
    }
}
```

尾插法建表，要维护尾指针：
```c
void createTail(LinkList head, int a[], int n) {
    LinkNode *r = head;      // r 始终指表尾
    int i;
    for (i = 0; i < n; i++) {
        LinkNode *s = (LinkNode *)malloc(sizeof(LinkNode));
        s->data = a[i];
        r->next = s;
        r = s;
    }
    r->next = NULL;
}
```

头插得到逆序，尾插得到正序。这个对比常考，也是逆置链表的常用手段。

### 各种代价

| 操作 | 时间 |
|---|---|
| 求表长 | O(n)，除非额外存 len |
| 按位置查找 | O(n) |
| 按值查找 | O(n) |
| 已知前驱插入删除 | O(1) |
| 未知位置插入删除 | O(n) |
| 头插、有尾指针的尾插 | O(1) |
| 逆置 | O(n) |

### 结构性开销

为了维持结构额外占的那部分。顺序表约等于零，只有一个 len 变量。单链表每个结点多一个指针，数据域占 d 字节、指针占 p 字节时，结构性开销比例是 `p / (d + p)`。双向链表两个指针，比例是 `2p / (d + 2p)`。

比如数据域是 int（4 字节），指针 4 字节，单链表的结构性开销比例是 4/(4+4) = 50%。存储密度也是 50%。这就是"链表空间利用率低"的定量说法。

## 循环链表和双向链表

单向循环链表把表尾的 next 指回头结点，形成环。判表尾的条件不再是 `p->next == NULL`，而是 `p->next == head`。

它的好处是从任一结点出发都能遍历全表。如果只设尾指针 r 不设头指针，`r->next` 就是首结点，能在 O(1) 内访问首尾，合并两个循环链表也是 O(1)。

双向链表每个结点两个指针：
```c
typedef struct dnode {
    ELEMType data;
    struct dnode *prior, *next;
} DLinkNode;
```

在 p 之后插入 s，四步，顺序有关键：
```c
s->prior = p;
s->next = p->next;
p->next->prior = s;   // 若 p 不是表尾
p->next = s;          // 这句必须最后
```

删除 p 的后继 q：
```c
q = p->next;
p->next = q->next;
q->next->prior = p;
free(q);
```

考试常考"以下四句代码的正确顺序"。原则是先处理新结点的两个指针，再处理原链表的两个指针，避免丢失后继。

双向循环链表里，头结点的 prior 指表尾，表尾的 next 指头结点。判空是 `head->next == head`，同时 `head->prior == head`。

## 顺序表和链表怎么选

这张表覆盖 2025 年第 21 题。

| 维度 | 顺序表 | 链表 |
|---|---|---|
| 存储方式 | 连续单元，逻辑相邻即物理相邻 | 任意单元，指针表示关系 |
| 访问方式 | 随机访问，按下标 O(1) | 顺序访问，走到第 i 个 O(n) |
| 按位置取值 | O(1) | O(n) |
| 插入删除 | O(n)，要移元素 | 已知前驱 O(1)，否则 O(n) |
| 空间分配 | 静态，要预先分配，可能浪费或溢出 | 动态，按需分配，不会溢出 |
| 空间开销 | 无指针域，存储密度为 1 | 每结点有指针域，密度小于 1 |
| 容量扩充 | 困难，C 数组不能自动扩容 | 容易，直接 malloc 新结点 |
| 适合 | 查询多、插删少、规模可预估 | 插删多、规模变化大、难预估 |

那道题的完整答法是四条：按主要操作（取元素查询为主选顺序表，插入删除为主选链表）；按数据规模（可预估且变化不大选顺序表，难预估频繁变化选链表）；按空间（空间紧张、元素多时指针开销占比大，选顺序表）；按是否需按下标定位或有序列访问（需要随机访问或折半查找只能选顺序表）。

## 算法设计题别丢分的三条铁律

先判边界。空表、满表、位置越界、空指针，每样对应一到两分。

再更新长度或指针。`L->len++`、`p->next = ...`，写完回头看一眼。

最后写复杂度。一句话，`// 时间复杂度 O(n)，空间复杂度 O(1)`。

删除类问题有个高效套路值得一提。2025 年第 30 题是"删除所有等于 x 的元素"，很多人第一反应是边找边删，那会退化成 O(n²)，而且表长一直在变，容易越界。正确做法是双指针覆盖：一个 write 指针记下一个该写的位置，一个 read 指针扫全表。

```c
int deleteAllX(SeqList *L, ELEMType x) {
    int read, write = 0, count = 0;
    if (L->len == 0) return 0;
    for (read = 0; read < L->len; read++) {
        if (L->elem[read] != x) {
            L->elem[write] = L->elem[read];  // 保留
            write++;
        } else {
            count++;                          // 计数
        }
    }
    L->len = write;
    return count;
}
```

这个读写指针模板能衍生出一堆题：删除重复元素、删除区间内的元素、有序表去重、串里删字符。一个模板打天下。

## 考前十分钟

1. 线性表是 n 个同类型元素的有限序列，逻辑上一对一。
2. 直接前驱后继唯一，前驱后继可能多个。
3. 地址公式 `LOC(aᵢ) = LOC(a₀) + i × L`。
4. 顺序表判空 `len==0`，判满 `len==maxSize`。
5. 插入：判满、判位置（`0≤pos≤len`）、从后往前移、赋值、`len++`。
6. 删除：判空、判位置（`0≤pos<len`）、保存、从前往后移、`len--`。
7. 插入平均移 n/2，删除平均移 (n-1)/2，都是 O(n)。
8. 顺序表取第 i 个 O(1)，链表 O(n)。
9. 头结点三个作用：统一空非空、统一首结点和其他位置、便于表头操作。
10. 链表插入两句 `s->next=p->next; p->next=s;` 不可颠倒。
11. 头插逆序，尾插正序。
12. 结构性开销 `p/(d+p)`，存储密度 `d/(d+p)`。
13. 循环链表判尾 `p->next == head`。
14. 顺序表和链表八维对比。

### C 组

**C-1**
```c
/* 用读写双指针覆盖：read 扫全表，write 记下一个保留元素该放的位置。
   非 x 就复制到 write 处并 write++；是 x 就跳过。
   时间 O(n)，空间 O(1)。 */
int deleteAllX(SeqList *L, ELEMType x) {
    int read, write = 0, count = 0;
    if (L->len == 0) return 0;
    for (read = 0; read < L->len; read++) {
        if (L->elem[read] != x) {
            L->elem[write] = L->elem[read];
            write++;
        } else {
            count++;
        }
    }
    L->len = write;
    return count;
}
```
评分：判空 1 分，读写指针思路 3 分，循环体 4 分，表长更新与返回值 2 分。

**C-2**
```c
/* 左右双向扫描加交换，类似快排的一趟划分：
   左指针找第一个非负元素，右指针找第一个负数，都存在时交换。
   时间 O(n)，空间 O(1)。 */
void partition(SeqList *L) {
    int i = 0, j = L->len - 1;
    ELEMType t;
    if (L->len <= 1) return;
    while (i < j) {
        while (i < j && L->elem[i] < 0) i++;
        while (i < j && L->elem[j] >= 0) j--;
        if (i < j) {
            t = L->elem[i]; L->elem[i] = L->elem[j]; L->elem[j] = t;
            i++; j--;
        }
    }
}
```
若追问"保持原有相对次序"，则不能用交换，得用两趟稳定搬运：先数负数个数，再从后往前稳定分配到两侧。

**C-3**
```c
/* 头插法逆置：摘下首结点之后的全部结点，逐个头插回头结点之后。
   只改指针，不申请空间。时间 O(n)，空间 O(1)。 */
void reverse(LinkList head) {
    LinkNode *p, *q;
    if (head == NULL || head->next == NULL) return;
    p = head->next;
    head->next = NULL;
    while (p != NULL) {
        q = p->next;          // 暂存后继，防止断链
        p->next = head->next;
        head->next = p;
        p = q;
    }
}
```

**C-4**
```c
/* 三个指针 pa、pb、pc。每次比较 pa 和 pb 的值，较小者尾插到 pc 后。
   某表走完后把另一表剩余段整体挂上。复用原结点。时间 O(m+n)，空间 O(1)。 */
LinkList merge(LinkList A, LinkList B) {
    LinkNode *pa = A->next, *pb = B->next;
    LinkNode *C = (LinkNode *)malloc(sizeof(LinkNode));
    LinkNode *pc = C;
    C->next = NULL;
    while (pa != NULL && pb != NULL) {
        if (pa->data <= pb->data) { pc->next = pa; pc = pa; pa = pa->next; }
        else                     { pc->next = pb; pc = pb; pb = pb->next; }
    }
    if (pa != NULL) pc->next = pa;
    else            pc->next = pb;
    return C;
}
```

**C-5**
```c

    LinkNode *p = head, *q;
    int count = 0;
    if (head == NULL) return 0;
    while (p->next != NULL) {
        if (p->next->data == x) {
            q = p->next;

```
`p = p->next` 必须放在 else 分支里。若删除后也前进，会漏检连续的多个 x，比如 3,3,3 只删掉一个。

**C-6**
```c
/* 双指针归并思想：i、j 在 A、B 上滑动，相等就写入 A 的输出位置 k 并三方同进；
   A 的元素小则 i++，B 的元素小则 j++。结果只写在下标 k ≤ i 处，不会覆盖未比较的 A 元素。 */
int intersection(SeqList *A, SeqList *B) {
    int i = 0, j = 0, k = 0;
    if (A->len == 0 || B->len == 0) { A->len = 0; return 0; }
    while (i < A->len && j < B->len) {
        if (A->elem[i] == B->elem[j]) {
            A->elem[k] = A->elem[i];
            k++; i++; j++;
        } else if (A->elem[i] < B->elem[j]) {
            i++;
        } else {
            j++;
        }
    }
    A->len = k;
    return k;
}
```
时间 O(m+n)，空间 O(1)。

**C-7**
顺序表优点：随机访问，按下标取值 O(1)；无指针开销，存储密度为 1；存储区连续，便于整体读写。

顺序表缺点：插入删除平均移 n/2 个元素，O(n)；需预先分配固定容量，可能溢出或浪费；扩充困难。

链表优点：插删只改指针，已知前驱时 O(1)；动态分配，容量可大可小；不要求连续空间，便于利用碎片。

链表缺点：只能顺序访问，按位置取值 O(n)；每结点有指针开销，存储密度小于 1；操作顺序不当会断链。

四个选择依据：主要操作是查询还是插删；数据规模能否预估、是否频繁变化；空间是否紧张、元素多少；是否需要随机访问或折半查找。
