### 21.（6 分）

**区别**，每个 1 分共 3 分：

插入删除的位置不同。栈只允许在一端（栈顶）插入和删除，另一端（栈底）固定；队列在两端分别操作，队尾插入、队头删除。

操作原则不同。栈是后进先出，队列是先进先出。

典型用途不同。栈适合需要回溯或逆序的场景，队列适合按到达顺序处理的场景。

可补充第四点：顺序存储时的关键问题不同，栈关心栈满判定，队列要解决假溢出，需用循环队列。

**典型应用**，各 1 分共 2 分：

栈：括号匹配、表达式求值与中缀转后缀、递归实现、函数调用栈、编辑器撤销、深度优先搜索。

队列：作业与进程调度、打印任务队列、键盘输入缓冲区、二叉树层序遍历、广度优先搜索。

表述完整 1 分。

### 23.（6 分）

**（1）`A[8][4]` 的地址（2 分）**
```
n = 12，k = 8×9/2 + 4 = 36 + 4 = 40
地址 = 1000 + 40×4 = 1160
```

**（2）存储单元数（2 分）**
`n(n+1)/2 = 12×13/2 = 78` 个。

**（3）`A[4][8]` 的地址（2 分）**
```
A[4][8]：i=4 < j=8，在上三角，利用对称性 A[i][j] = A[j][i]
转成 A[8][4]，k = 8×9/2 + 4 = 40
地址 = 1000 + 40×4 = 1160
```
为什么相同：对称矩阵满足 `A[i][j] = A[j][i]`，压缩存储时只保存其中一个（本题存下三角）。上三角的元素通过对称性去查下三角的存储位置，因此 `A[4][8]` 和 `A[8][4]` 映射到同一个单元，地址必然相同。这正是"只存一半能省一半空间"的根本原因。

### 25.（6 分）

特征向量定义：设 `P = p₁p₂…pₘ`，`nᵢ` 是子串 `p₁p₂…pᵢ₋₁` 中既是真前缀又是真后缀的最长串长度，`n₁ = 0`。

| i | 考察子串 | 从长到短检查 | nᵢ |
|---|---|---|---|
| 1 | 空串 | 无前后缀 | 0 |
| 2 | `a` | 无真前后缀 | 0 |
| 3 | `ab` | `a` ≠ `b` | 0 |
| 4 | `aba` | 长1：`a`=`a` ✓ | 1 |
| 5 | `abaa` | 长1：`a`=`a` ✓；长2：`ab`≠`aa` | 1 |

## 四、算法阅读题（20 分）

### 26.（5 分）

**（1）`i++`（1 分）**
**（2）`L->elem[i-1] = L->elem[i]`（2 分）**
**（3）`L->len--`（1 分）**

**（4）说明（1 分）**：这是顺序表的删除操作。pos 处元素已保存到 `*x`，接下来把 pos+1 到表尾的所有元素依次前移一位，最后表长减一。

完整代码：
```c
int fun(SeqList *L, int pos, ELEMType *x)
{
    int i;
    if (L->len == 0) return 0;
    if (pos < 0 || pos >= L->len) return -1;
    *x = L->elem[pos];
    for (i = pos + 1; i < L->len; i++)
        L->elem[i - 1] = L->elem[i];
    L->len--;
    return 1;
}
```
对比陷阱：插入是从后往前移（`i = len; i > pos; i--`），删除是从前往后移（`i = pos+1; i < len; i++`）。方向搞反会覆盖数据。

### 27.（5 分）

**（1）`s->next = p->next`（1 分）**
**（2）`s->prior = p`（1 分）**
**（3）`p->next->prior = s`（2 分）**

**（4）（1 分）**
先执行 `p->next = s;` 后，`p->next` 已经变成 s 了。此时再执行 `s->next = p->next;` 相当于 `s->next = s`，新结点自己指向自己形成自环，而 p 原来的后继结点及其后整段链表全部丢失，无法再访问。

正确顺序：先让新结点接上原后继，再让新结点的前驱指向 p，再让原后继的前驱指向 s，最后才改 `p->next = s`。
口诀是先把新结点的两个指针接好，再改邻居，最后改自己。

### 28.（5 分）

**（1）`p->data > p->next->data`（2 分）**
**（2）`p = p->next`（1 分）**
**（3）`1`（1 分）**

**（4）（1 分）**
`head->next == NULL` 表示这是空表，只有头结点没有实际数据结点。空表没有相邻元素对，谈不上逆序，按递增有序的平凡情形返回 1（真）。

完整代码：
```c
int fun(LinkList head)
{
    LinkNode *p;
    if (head == NULL) return 0;
    if (head->next == NULL) return 1;
    p = head->next;
    while (p->next != NULL) {
        if (p->data > p->next->data) return 0;
        p = p->next;
    }
    return 1;
}
```

### 29.（5 分）

**（1）功能（3 分）**
`fun` 统计二叉树中度为 1 的结点个数，即"只有一个孩子"的结点数。
空树返回 0。左右都空返回 0（叶子度为 0，不计入）。恰好一个为空时返回 `1 + 左子树结果 + 右子树结果`（本结点计入）。两个都不空时返回左子树结果加右子树结果（本结点度为 2，不计入）。

**（2）返回结果（2 分）**

```
            A          ← 两个孩子 B、C，度为 2，不计
          /   \
         B     C       ← B 有 2 个孩子，不计
```

## 五、算法设计题（10 分）

### 30. 删除有序顺序表中重复的元素

**（1）算法思想（3 分）**

由于表已经有序，所有相同的元素必然连续排列。因此可以用读写双指针一趟扫描：

read 指针遍历整个表；write 指针记录下一个不重复元素应写入的位置；对每个 read，若它与刚写入的上一个元素（`elem[write-1]`）不同，就写到 `elem[write]` 并 `write++`；若相同说明是重复元素，跳过（相当于删除）；扫描结束后 `len = write`。

关键点是比较对象是"已写入的最后一个元素"而不是"原表的前一个元素"，所以即使前面的元素被覆盖也不会出错。

**（2）函数实现（5 分）**

```c
int deleteDuplicates(SeqList *L)
{
    int read, write;

    if (L->len <= 1) return 0;      /* 空表或只有一个元素，无需处理 */

    write = 1;                       /* 第一个元素一定保留 */
    for (read = 1; read < L->len; read++) {
        if (L->elem[read] != L->elem[write - 1]) {
            L->elem[write] = L->elem[read];   /* 保留：搬到 write 处 */
            write++;
        }
        /* 否则是重复元素，直接跳过 */
    }

    int removed = L->len - write;
    L->len = write;                  /* 更新表长 */
    return removed;                  /* 返回被删除的重复元素个数 */
}
```

运行验证，`L.elem = [2,2,3,3,3,5,7,7,9]`，`len = 9`：
```
初值 write = 1
read=1: elem[1]=2 与 elem[0]=2 相同，跳过
read=2: elem[2]=3 与 elem[0]=2 不同 → elem[1]=3, write=2
read=3: elem[3]=3 与 elem[1]=3 相同，跳过
read=4: elem[4]=3 与 elem[1]=3 相同，跳过
read=5: elem[5]=5 与 elem[1]=3 不同 → elem[2]=5, write=3
read=6: elem[6]=7 与 elem[2]=5 不同 → elem[3]=7, write=4
read=7: elem[7]=7 与 elem[3]=7 相同，跳过
read=8: elem[8]=9 与 elem[3]=7 不同 → elem[4]=9, write=5
最终 len = 5，elem[0..4] = [2, 3, 5, 7, 9]，删除 4 个
```

**（3）复杂度（2 分）**
时间 O(n)，一趟扫描，每元素比较一次最多移动一次。空间 O(1)，只用了 read、write、removed 三个辅助变量，原地完成。

评分：算法思想 3 分（说清"因有序所以重复连续"1 分、"读写双指针"1 分、"比较对象是已写入的最后一个元素"1 分）；代码 5 分（边界判断 1 分、循环逻辑 3 分、更新 len 与返回值 1 分）；复杂度 2 分。

对比易错解法：边扫边删最坏是 (n-1) 次删除，每次 O(n)，总 O(n²)，且表长频繁变化容易越界。
