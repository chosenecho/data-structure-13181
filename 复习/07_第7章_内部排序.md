# 第 7 章 内部排序

卷面 9 分左右。真正要背的是一张对比表，真正要练的是手工走一趟排序。

2025 年那份卷子在排序上出了三道题：第 8 题数起泡排序第一趟交换几次，第 9 题判断哪个序列是大根堆，第 16 题填空盒子排序的时间复杂度。三道都不难，但第 8 题很多人会数错。数交换次数必须真的一段段比过去，不能凭感觉。

对比表那张是全书性价比最高的一张表。稳定不稳定、时间和空间复杂度，选择题填空题从这里出，解答题问"选哪种排序"也靠它。

## 基本概念

| 术语 | 定义 |
|---|---|
| 排序 | 把一组记录按某关键字递增或递减重排 |
| 主关键字 | 能唯一标识记录的关键字，如学号 |
| 次关键字 | 不能唯一标识，如姓名 |
| 逆序对 | 排列中 i<j 但 a[i]>a[j] 的一对 |
| 内部排序 | 数据全在内存，不访问外存 |
| 外排序 | 数据太大，需借助外存分批排后归并 |
| 稳定排序 | 排序前后关键值相等的记录相对次序不变 |
| 不稳定排序 | 存在某些输入使相等关键字次序被改变 |

稳定性只针对关键字相等的记录，不是针对整个序列。

例：`[3a, 1, 3b]`，3a 和 3b 关键字相同，a 在 b 前。排序后若是 `[1, 3a, 3b]` 就稳定，若是 `[1, 3b, 3a]` 就不稳定。

评价排序算法看四条：时间效率（比较次数加移动次数）、空间效率（辅助空间，O(1) 叫原地排序）、稳定性、适用性（对存储结构的要求、对初始数据状态的敏感度）。

按思想分五类：插入排序（直接插入、折半插入、希尔）、交换排序（起泡、快速）、选择排序（简单选择、堆）、归并排序（二路归并）、分配排序（盒子、基数）。

## 插入排序

### 直接插入

把序列分成有序区和无序区，开始有序区只有 a[0]。每趟取无序区第一个元素，在有序区里从后往前找位置插入。

```c
void insertSort(int a[], int n) {
    int i, j, t;
    for (i = 1; i < n; i++) {
        if (a[i] < a[i - 1]) {
            t = a[i];
            j = i - 1;
            while (j >= 0 && a[j] > t) {
                a[j + 1] = a[j];
                j--;
            }
            a[j + 1] = t;
        }
    }
}
```

| 情况 | 比较次数 | 移动次数 | 时间 |
|---|---|---|---|
| 最好（已升序有序） | n-1 | 0 | O(n) |
| 最坏（逆序） | n(n-1)/2 | n(n-1)/2 + (n-1) | O(n²) |
| 平均 | 约 n²/4 | 约 n²/4 | O(n²) |

空间 O(1)，稳定。

为什么稳定：比较用 `a[j] > t` 而不是 `>=`。遇到相等元素时循环停止，新元素插在它后面，原相对次序不变。

### 折半插入

找插入位置时用折半查找，比较次数从 O(n²) 降到 O(n log n)，但移动次数不变，仍是 O(n²)，所以总时间还是 O(n²)。

只能用于顺序存储，因为折半查找要随机访问。稳定。

### 希尔排序

取递减的增量序列 `d₁ > d₂ > … > dₖ = 1`。对每个增量 d，把序列分成 d 组（下标相差 d 的在一组），组内做直接插入排序。随着 d 减小序列逐渐基本有序，d = 1 时做最后一次直接插入排序。

教材默认增量：`d₁ = ⌊n/2⌋`，之后 `d = ⌊d/2⌋` 直到 1。

例：n = 9，`9,1,5,8,3,7,4,6,2`，增量 4、2、1：
```
初始: [9, 1, 5, 8, 3, 7, 4, 6, 2]
d=4: 分组 {9,3} {1,7} {5,4} {8,6} {2}
     组内排序后 → [2, 1, 4, 6, 3, 7, 5, 8, 9]
d=2: 分组 {2,4,3,5,9} {1,6,7,8}
     组内排序后 → [2, 1, 3, 6, 4, 7, 5, 8, 9]
d=1: 整体直接插入排序 → [1, 2, 3, 4, 5, 6, 7, 8, 9]
```

性能：平均 `O(n^1.3)`，最坏 O(n²)，与增量序列的选取直接相关。空间 O(1)。不稳定，因为相同关键字的元素可能被分到不同组，跨组移动后次序变了。只能用于顺序存储。

## 交换排序

### 起泡排序

从前往后两两比较相邻元素，逆序则交换。一趟下来最大的元素冒到末尾。重复 n-1 趟，或者提前发现无交换就终止。

```c
void bubbleSort(int a[], int n) {
    int i, j, t, flag;
    for (i = 0; i < n - 1; i++) {
        flag = 0;
        for (j = 0; j < n - 1 - i; j++)
            if (a[j] > a[j + 1]) {
                t = a[j]; a[j] = a[j + 1]; a[j + 1] = t;
                flag = 1;
            }
        if (flag == 0) break;
    }
}
```

| 情况 | 比较次数 | 交换次数 | 时间 |
|---|---|---|---|
| 最好（已有序，带 flag） | n-1 | 0 | O(n) |
| 最坏（逆序） | n(n-1)/2 | n(n-1)/2 | O(n²) |
| 平均 | 约 n²/2 | 约 n²/4 | O(n²) |

空间 O(1)，稳定。一趟起泡后最大元素到达最终位置，这是最常见的考查点。

### 2025 年第 8 题

对 `25, 13, 35, 10, 29, 27` 从小到大起泡排序，第一趟需交换几次？

一趟就是从前往后扫一遍：
```
初始：      25  13  35  10  29  27
j=0: 25>13 → 交换 → 13  25  35  10  29  27   （第1次）
j=1: 25<35 → 不换
j=2: 35>10 → 交换 → 13  25  10  35  29  27   （第2次）
j=3: 35>29 → 交换 → 13  25  10  29  35  27   （第3次）
j=4: 35>27 → 交换 → 13  25  10  29  27  35   （第4次）
```
交换 4 次，答案 C。一趟结束时最大的 35 已冒到末尾。

同类题可以拿 `49, 38, 65, 97, 76, 13, 27, 49` 再练一遍。

### 快速排序

选一个枢轴，把序列分成左边都小于等于枢轴、右边都大于枢轴的两段，枢轴放到最终位置，然后对左右两段递归。

```c
int partition(int a[], int low, int high) {
    int pivot = a[low];
    while (low < high) {
        while (low < high && a[high] > pivot) high--;
        a[low] = a[high];
        while (low < high && a[low] <= pivot) low++;
        a[high] = a[low];
    }
    a[low] = pivot;
    return low;
}

void quickSort(int a[], int low, int high) {
    if (low < high) {
        int p = partition(a, low, high);
        quickSort(a, low, p - 1);
        quickSort(a, p + 1, high);
    }
}
```

例：对 `50, 26, 38, 80, 70, 90, 10, 40` 以 50 为枢轴划分一趟。
```
初始：      50  26  38  80  70  90  10  40      low=0, high=7, pivot=50
high 左扫找 ≤50: 40 → a[0]=40 → 40 26 38 80 70 90 10 40
low 右扫找 >50:  80 → a[7]=80 → 40 26 38 80 70 90 10 80 ; low=3
high 左扫找 ≤50: 10 → a[3]=10 → 40 26 38 10 70 90 10 80 ; high=6
low 右扫找 >50:  70 → a[6]=70 → 40 26 38 10 70 90 70 80 ; low=4
high 左扫: 90>50 继续，70>50 继续，low=4=high=4 停止
a[4]=pivot=50 → 40 26 38 10 50 90 70 80
```
结果 `[40, 26, 38, 10, 50, 90, 70, 80]`，枢轴 50 的最终位置是下标 4。左侧 `{40,26,38,10}` 全部小于等于 50，右侧 `{90,70,80}` 全部大于 50。

性能：最好 O(n log₂n)，最坏 O(n²)（序列已有序或逆序，每次都分成 1 和 n-1），平均 O(n log₂n)。空间 O(log₂n)（递归栈），最坏 O(n)。不稳定。

平均性能最好的内部排序算法。

枢轴优化有两个办法：三元取中法，取首、中、尾三个元素的中位数作枢轴；随机化，随机选一个元素。

## 选择排序

### 简单选择

每趟从无序区选出最小值，与无序区第一个元素交换。

```c
void selectSort(int a[], int n) {
    int i, j, k, t;
    for (i = 0; i < n - 1; i++) {
        k = i;
        for (j = i + 1; j < n; j++)
            if (a[j] < a[k]) k = j;
        if (k != i) { t = a[i]; a[i] = a[k]; a[k] = t; }
    }
}
```

比较次数固定为 `n(n-1)/2`，与初始状态无关，时间 O(n²)。移动次数最好 0，最坏 O(n)。空间 O(1)，不稳定。

### 堆排序

堆的定义：完全二叉树，大根堆中每个结点值都大于等于左右孩子，堆顶是最大值；小根堆反之，堆顶是最小值。

用数组顺序存，下标从 1 开始：结点 i 的父是 ⌊i/2⌋，左孩子 2i，右孩子 2i+1。

### 2025 年第 9 题

能构成大根堆的关键字序列是
A. `5,8,1,3,9,6,2,7`　B. `9,8,1,7,5,6,2,3`
C. `9,8,6,3,5,1,2,7`　D. `9,8,6,7,5,1,2,3`

判定办法：对每个下标 i（1-based），检查 `a[i] ≥ a[2i]` 且 `a[i] ≥ a[2i+1]`。

A：`a[1]=5`，`a[2]=8 > 5`，不是。
B：`a[1]=9` 不小于 8 和 1，`a[2]=8` 不小于 7 和 5，但 `a[3]=1`，左孩子 `a[6]=6 > 1`，不是。
C：前三个都满足，但 `a[4]=3`，它的左孩子是 `a[8]=7`，`3 < 7`，不是。
D：`9 ≥ 8,6`，`8 ≥ 7,5`，`6 ≥ 1,2`，`7 ≥ 3`，全部满足。答案 D。

考场技巧是从上往下逐层检查，一旦某结点的孩子比它大就立即排除。

### 堆排序过程

```
1. 建初始堆：从最后一个非叶子结点 ⌊n/2⌋ 开始，依次向前对每个结点做向下筛
2. 交换：堆顶最大值与堆的最后一个元素交换，最大值归位
3. 重建：堆长度减 1，对新堆顶做一次向下筛
4. 重复 2 到 3，直到堆长度为 1
```

建堆例：`49, 38, 65, 97, 76, 13, 27`，n = 7，最后一个非叶子结点是 3。
```
初始：[49, 38, 65, 97, 76, 13, 27]

① 调整结点 3（65）：孩子 6(13)、7(27)，65 都大于等于，不调整
② 调整结点 2（38）：孩子 4(97)、5(76)，97 最大，交换 38 和 97
   → [49, 97, 65, 38, 76, 13, 27]
   结点 4 已是叶子，停止
③ 调整结点 1（49）：孩子 2(97)、3(65)，97 最大，交换 49 和 97
   → [97, 49, 65, 38, 76, 13, 27]
   继续筛结点 2（49）：孩子 4(38)、5(76)，76 最大，交换 49 和 76
   → [97, 76, 65, 38, 49, 13, 27]
   结点 5 已是叶子，停止

初始大根堆：[97, 76, 65, 38, 49, 13, 27]
```

性能：建初始堆 O(n)，每次调整 O(log₂n) 共 n-1 次，总时间 O(n log₂n)，最好最坏平均都是这个。空间 O(1)，不稳定。

适合大规模数据，且效率稳定，没有最坏退化。

有个反直觉的地方要记住：想升序就建大根堆，每次都把最大值放到末尾。

## 归并排序

分治：把序列分成两半，分别排序，再合并两个有序段。

```c
void merge(int a[], int t[], int low, int mid, int high) {
    int i = low, j = mid + 1, k = low;
    while (i <= mid && j <= high)
        t[k++] = (a[i] <= a[j]) ? a[i++] : a[j++];
    while (i <= mid)  t[k++] = a[i++];
    while (j <= high) t[k++] = a[j++];
    for (k = low; k <= high; k++) a[k] = t[k];
}

void mergeSort(int a[], int t[], int low, int high) {
    if (low < high) {
        int mid = (low + high) / 2;
        mergeSort(a, t, low, mid);
        mergeSort(a, t, mid + 1, high);
        merge(a, t, low, mid, high);
    }
}
```

时间 O(n log₂n)，最好最坏平均都是。空间 O(n)，不是原地排序。稳定，因为合并时用 `a[i] <= a[j]`，相等时优先取左边。

例：`49, 38, 65, 97, 76, 13, 27, 49` 的迭代归并：
```
初始:      [49] [38] [65] [97] [76] [13] [27] [49]
第1趟(w=1): [38,49] [65,97] [13,76] [27,49]  = 38 49 65 97 13 76 27 49
第2趟(w=2): [38,49,65,97] [13,27,49,76]
第3趟(w=4): [13,27,38,49,49,65,76,97]
```

## 分配排序

### 盒子排序

根据关键字取值范围设若干个盒子（相当于队列），按关键字放进去，再按盒子顺序收集。

时间 `O(n + m)`，m 是盒子个数。关键字值域远大于 n 时效率极低。空间 `O(n + m)`，稳定。

2025 年第 16 题：若初始待排序的元素个数为 n，则盒子排序的时间复杂度为＿＿。

答 `O(n)`（更严格是 `O(n + m)`）。教材语境下"盒子数量固定"时常直接答 O(n)，若题目给了盒子个数 m 就写 `O(n+m)`。

### 基数排序

把关键字看成 d 位，从最低位开始，依次对每一位做分配和收集，d 趟后有序。

例：`123, 45, 67, 89, 101, 234, 56`
```
第1趟（个位）：
  分配: 1→[101] 3→[123] 4→[234] 5→[45] 6→[56] 7→[67] 9→[89]
  收集: 101, 123, 234, 45, 56, 67, 89
第2趟（十位）：
  101→0, 123→2, 234→3, 45→4, 56→5, 67→6, 89→8
  收集: 101, 123, 234, 45, 56, 67, 89
第3趟（百位）：
  101→1, 123→1, 234→2, 45→0, 56→0, 67→0, 89→0
  收集: 45, 56, 67, 89, 101, 123, 234   有序
```

时间 `O(d(n + r))`，d 是位数、r 是基数（十进制 r=10）。空间 `O(n + r)`。稳定。只适合整数或字符串这类能拆位的关键字。

这张表要能默写。

| 算法 | 平均时间 | 最坏时间 | 最好时间 | 空间 | 稳定性 | 原地 |

| 二路归并 | O(n log n) | O(n log n) | O(n log n) | O(n) | 稳定 | 否 |
| 盒子排序 | O(n+m) | O(n+m) | O(n+m) | O(n+m) | 稳定 | 否 |
| 基数排序 | O(d(n+r)) | O(d(n+r)) | O(d(n+r)) | O(n+r) | 稳定 | 否 |

### 稳定性的口诀

稳定的：插入、折半插入、起泡、归并、基数、盒子。
不稳定的：希尔、快速、简单选择、堆。

口诀：插、冒、归、基，稳；希、快、选、堆，不稳。

### 复杂度速记

| 记忆点 | 算法 |
|---|---|
| 时间 O(n log n) | 快排（平均）、堆排、归并 |
| 最坏会退化成 O(n²) | 快排、希尔、插入类、交换类、选择类 |
| 最坏仍 O(n log n) | 只有堆排和归并 |
| 最好能到 O(n) | 只有直接插入和起泡 |
| 空间 O(1) | 插入类、起泡、简单选择、堆排、希尔 |
| 空间 O(n) | 归并、基数、盒子 |
| 空间 O(log n) | 快排（递归栈） |

### 怎么选

| 场景 | 首选 | 理由 |
|---|---|---|
| 数据量小（n ≤ 100） | 直接插入、起泡、简单选择 | 实现简单，常数小 |
| 接近有序 | 直接插入、起泡 | 最好 O(n) |
| 数据量大、无序、内存充足 | 快速排序 | 平均最快 |
| 数据量大、要求效率稳定 | 堆排序 | 最坏也是 O(n log n) 且 O(1) 空间 |
| 需要稳定排序 | 归并、基数 | 稳定的高效算法 |
| 稳定加内存充足 | 二路归并 | O(n log n) 且稳定 |
| 整数或字符串、位数少 | 基数排序 | 无需比较，接近 O(n) |
| 内存极紧张 | 堆排序、希尔 | O(1) 空间且较快 |

## 考前十分钟

1. 内部排序指数据全在内存。稳定指相等关键字的相对次序不变。
2. 五类：插入、交换、选择、归并、分配。
3. 直接插入最好 O(n)，最坏 O(n²)，空间 O(1)，稳定。
4. 折半插入比较次数 O(n log n)，移动次数仍 O(n²)，总时间 O(n²)，稳定。
5. 希尔增量 `⌊n/2⌋` 递减到 1，平均 O(n^1.3)，不稳定，只能顺序存储。

11. 堆排序时间恒为 O(n log n)，空间 O(1)，不稳定。
12. 归并时间恒为 O(n log n)，空间 O(n)，稳定。
13. 基数排序 `O(d(n+r))`，稳定，不是原地。
14. 稳定：插、折、冒、归、基、盒；不稳定：希、快、选、堆。
15. 最坏仍 O(n log n) 的只有堆排和归并；最好能到 O(n) 的只有直接插入和起泡。

**C-1**
```c
/* 把 a[0..i-1] 看作有序区，把 a[i] 插入其中：
   从后往前找位置，比 a[i] 大的依次后移，最后放入空位。
   最好 O(n)，最坏 O(n^2)，平均 O(n^2)。空间 O(1)。稳定。 */
void insertSort(int a[], int n) {
    int i, j, t;
    for (i = 1; i < n; i++) {
        if (a[i] < a[i - 1]) {
            t = a[i];
            j = i - 1;
            while (j >= 0 && a[j] > t) {
                a[j + 1] = a[j];
                j--;
            }
            a[j + 1] = t;
        }
    }
}
```

**C-2**
```c
int partition(int a[], int low, int high) {
    int pivot = a[low];
    while (low < high) {
        while (low < high && a[high] > pivot) high--;
        a[low] = a[high];
        while (low < high && a[low] <= pivot) low++;
        a[high] = a[low];
    }
    a[low] = pivot;
    return low;
}

void quickSort(int a[], int low, int high) {
    if (low < high) {
        int p = partition(a, low, high);
        quickSort(a, low, p - 1);
        quickSort(a, p + 1, high);
    }
}
```
枢轴选择的影响：每次划分若能把序列分成两个长度相近的子序列，递归深度 log₂n，时间 O(n log₂n)，空间 O(log₂n)，这是最好和平均情况。若枢轴总取到极值（序列已有序或逆序而固定取首元素），每次都分成长度 1 和 n-1 的两段，递归深度 n，退化为 O(n²)，空间 O(n)。优化办法是三元取中法（取首、中、尾的中位数）或随机化选枢轴。

```c
void heapAdjust(int a[], int s, int m) {
    int t = a[s], j;
    for (j = 2 * s; j <= m; j = 2 * j) {

    }
    a[s] = t;
}

void heapSort(int a[], int n) {
    int i, t;
    for (i = n / 2; i >= 1; i--)
        heapAdjust(a, i, n);

    for (i = n; i > 1; i--) {
        t = a[1]; a[1] = a[i]; a[i] = t;
        heapAdjust(a, 1, i - 1);
    }
}
```

**C-4**
```c
void merge(int a[], int t[], int low, int mid, int high) {
    int i = low, j = mid + 1, k = low;
    while (i <= mid && j <= high)
        t[k++] = (a[i] <= a[j]) ? a[i++] : a[j++];
    while (i <= mid)  t[k++] = a[i++];
    while (j <= high) t[k++] = a[j++];
    for (k = low; k <= high; k++) a[k] = t[k];
}

void mergeSort(int a[], int t[], int low, int high) {
    if (low < high) {
        int mid = (low + high) / 2;
        mergeSort(a, t, low, mid);
        mergeSort(a, t, mid + 1, high);
        merge(a, t, low, mid, high);
    }
}
```

```c
/* 小根堆法，最优解：维护大小为 k 的小根堆，堆顶是"当前这 k 个最大元素中最小的那个"。

   ③ 遍历结束后堆中 k 个元素即前 k 大
   总时间 O(n log k)。k 远小于 n 时远优于全排序的 O(n log n)。 */
```

方向要记清：求前 k 大用小根堆，求前 k 小用大根堆，反直觉但必须想明白。

**C-6**
（1）稳定排序：直接插入、折半插入、起泡、二路归并、基数、盒子。
不稳定排序：希尔、快速、简单选择、堆。

（2）实际应用常需要多关键字排序，标准做法是先按次关键字排、再按主关键字排，且第二次必须用稳定排序，这样才能保证主关键字相同时次关键字仍有序。

例：学生成绩表要求"按成绩降序，成绩相同按学号升序"。先按学号升序排，再按成绩降序用稳定排序排。结果里成绩相同的同学因为第一步已按学号排好，第二步不会再被打乱。若第二步用了不稳定排序，成绩相同的同学学号次序可能被打乱，结果不合要求。

**C-7**
（1）

| | 快速排序 | 堆排序 | 二路归并 |
|---|---|---|---|
| 平均时间 | O(n log n) | O(n log n) | O(n log n) |
| 最坏时间 | O(n²) | O(n log n) | O(n log n) |
| 空间 | O(log n) | O(1) | O(n) |
| 稳定性 | 不稳定 | 不稳定 | 稳定 |
| 适用 | 无序、内存充足、不要求稳定 | 要求最坏有保障、内存紧张 | 要求稳定、内存充足 |

（2）选堆排序。
理由：数据量大必须 O(n log n) 级别，排除插入和选择类。内存只多几 MB，辅助空间必须小。归并要 O(n) 额外数组（10^6 个 int 约 4 MB，勉强但题目强调"只有几 MB"），快排递归栈虽小但有最坏 O(n²) 风险。堆排序时间恒为 O(n log n) 无最坏退化，空间 O(1)，最稳妥。若不要求稳定，它是最优选择。

**C-8**
（1）因为堆调整采用向下筛，只能把结点往下调。叶子没有孩子，本身就是合法的堆，无需调整。从 ⌊n/2⌋ 开始向前调整，能保证每次调整某结点时它的左右子树已经是堆，向下筛才正确。若从根开始，子树的堆性质还没建立，调整结果不可靠。⌊n/2⌋ 之后的结点全是叶子，无需处理。

（2）大根堆的堆顶是当前全部元素中的最大值。把它与堆末元素交换，最大值就放到最终位置（末尾），堆长度减一后重建大根堆取新的最大值放到新末尾，如此反复。每一步都从剩余元素取出最大值放到后面，最终序列就是从小到大，即升序。

（3）建堆和向下筛的过程中，元素是跨越多个位置移动的，不是相邻交换。比如把堆顶最大值换到末尾时，末尾原本的元素被搬到堆顶，可能被一路筛到很远的位置，这个过程中它可能跨过与自己关键字相等的元素，导致相等元素相对次序改变。所以堆排序不稳定。
