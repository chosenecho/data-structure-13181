# 第 6 章 图结构

这一章 12 分上下。选择填空考概念和计数，解答题基本锁定最小生成树，这几年考的是克鲁斯卡尔。

图的概念多，但真正要动脑的地方少。度、边数、连通分量这些是数出来的；Prim 和 Kruskal 是画出来的；拓扑排序和 Dijkstra 通常以填空或"写过程"的形式出现，按部就班填表就行。

有个地方容易栽跟头：Dijkstra 不能处理负权边。这个知识点选择题爱考，理由要能说清，贪心的前提是"已经确定的路径不会再变短"，负权会打破这个前提。

## 基本概念

图 G = (V, E)，V 是顶点的非空有限集，E 是边的有限集。

| 术语 | 定义 | 记忆 |
|---|---|---|
| 无向边 `(vi, vj)` | 无方向，圆括号 | `(1,2)` 与 `(2,1)` 相同 |
| 有向边（弧）`<vi, vj>` | 有方向，尖括号 | `<1,2>` 不等于 `<2,1>` |
| 弧尾 | 箭尾，起点 | `<vi, vj>` 中 vi 是弧尾 |
| 弧头 | 箭头，终点 | `<vi, vj>` 中 vj 是弧头 |
| 无向图 | 所有边都是无向边 | 边数记 e |
| 有向图 | 所有边都是有向边 | 弧数记 e |
| 带权图（网） | 每条边带一个数值 | 用于最短路径、最小生成树 |
| 邻接点 | 有边直接相连的两个顶点 | 无向图中互为邻接点 |
| 顶点的度 TD(v) | 与 v 相关联的边的数目 | 无向图专用 |
| 入度 ID(v) | 以 v 为弧头的弧数 | 有向图 |
| 出度 OD(v) | 以 v 为弧尾的弧数 | 有向图 |
| 完全图 | 任意两顶点间都有边 | 无向 n(n-1)/2，有向 n(n-1) |
| 简单路径 | 顶点不重复的路径 | — |
| 简单回路 | 除首尾外顶点不重复的回路 | — |
| 路径长度 | 路径上边的数目 | 不是顶点数 |
| DAG | 有向无环图 | 拓扑排序的对象 |
| 连通分量 | 无向图的极大连通子图 | "极大"是关键 |
| 强连通图 | 任意两顶点互相可达 | 双向都要有路径 |
| 弱连通图 | 忽略方向后连通 | — |

### 几个必背的数

| 情形 | 结论 |
|---|---|
| 无向完全图边数 | `n(n-1)/2` |
| 有向完全图弧数 | `n(n-1)` |
| 连通无向图最少边数 | `n - 1`（此时是树） |
| 强连通有向图最少弧数 | `n`（构成一个环） |
| 无向图所有顶点度之和 | `2e` |
| 有向图入度之和等于出度之和 | `e` |
| 生成树的顶点数和边数 | `n` 和 `n - 1` |

2025 年第 7 题：若无向图的顶点个数为 n，则该图边的数目最多为。答案 `n(n-1)/2`，就是无向完全图。

第 17 题填空：在无向图中，与顶点相关联的边的数目称为该顶点的＿＿。答案是度。

第 18 题填空：图中不存在回路的有向图称为＿＿。答案是有向无环图，也就是 DAG。

### 度与边数的换算

无向图 `Σ TD(vi) = 2e`，所以度之和必为偶数。有向图 `Σ ID(vi) = Σ OD(vi) = e`，且 `TD(v) = ID(v) + OD(v)`。

例：10 个顶点的无向图，度数之和为 30，边数是 `30/2 = 15`。

例：有向图有 8 个顶点 20 条弧，某顶点出度 3、入度 2，它的度是 5。

## 存储结构

### 邻接矩阵

用 n×n 的二维数组表示顶点 i 到 j 是否有边。

```c
#define MAXV 100
typedef struct {
    ELEMType vexs[MAXV];
    int arcs[MAXV][MAXV];
    int n, e;
} MGraph;
```

| 图类型 | 矩阵特点 | 顶点度 |
|---|---|---|
| 无向图 | 矩阵对称 | 第 i 行之和等于 TD(vi) |
| 有向图 | 一般不对称 | 第 i 行之和是出度，第 i 列之和是入度 |
| 带权图 | A[i][j] 存权值，无边用 ∞ | 同上 |

空间 O(n²)，与边数无关，适合稠密图。

### 邻接表

每个顶点一个链表，存该顶点的所有邻接点。

```c
typedef struct ArcNode {
    int adjvex;
    int weight;
    struct ArcNode *nextarc;
} ArcNode;

typedef struct VNode {
    ELEMType data;
    ArcNode *firstarc;
} VNode, AdjList[MAXV];

typedef struct {
    AdjList vertices;
    int n, e;
} ALGraph;
```

| | 邻接矩阵 | 邻接表 |
|---|---|---|
| 空间 | O(n²) | O(n + e) |
| 判断 (i,j) 是否有边 | O(1) | O(deg(i)) |
| 遍历某顶点的邻接点 | O(n) | O(deg(i))，更快 |
| 适合 | 稠密图 | 稀疏图 |
| 表示是否唯一 | 唯一 | 与边结点插入次序有关，不唯一 |

填空题常考：n 个顶点 e 条边的无向图，邻接表里有 `2e` 个边结点，因为每条边在两个顶点的链表里各出现一次。有向图是 e 个。

## 遍历

### DFS

从某顶点出发访问它，然后递归访问每个未访问的邻接点，走不通就回溯。

```c
int visited[MAXV];

void DFS(MGraph *G, int v) {
    int j;
    visited[v] = 1;
    printf("%d ", G->vexs[v]);
    for (j = 0; j < G->n; j++)
        if (G->arcs[v][j] == 1 && !visited[j])
            DFS(G, j);
}
```

辅助结构是栈（递归调用栈）。时间：邻接矩阵 O(n²)，邻接表 O(n+e)。

### BFS

从某顶点出发访问它，然后逐层访问它的所有未访问邻接点，像水波扩散。

```c
void BFS(MGraph *G, int v) {
    int q[MAXV], front = 0, rear = 0, i, j;
    for (i = 0; i < G->n; i++) visited[i] = 0;
    visited[v] = 1; printf("%d ", G->vexs[v]);
    q[rear++] = v;
    while (front != rear) {
        i = q[front++];
        for (j = 0; j < G->n; j++)
            if (G->arcs[i][j] == 1 && !visited[j]) {
                visited[j] = 1;
                printf("%d ", G->vexs[j]);
                q[rear++] = j;
            }
    }
}
```

辅助结构是队列。

### 对比

| | DFS | BFS |
|---|---|---|
| 辅助结构 | 栈或递归 | 队列 |
| 遍历方式 | 一条路走到底再回溯 | 一层层扩散 |
| 类似二叉树 | 先序遍历 | 层序遍历 |
| 生成树 | 深度优先生成树 | 广度优先生成树 |
| 适用 | 找路径、判环、连通分量 | 无权图最短路径、层序 |

同一个图从同一顶点出发，DFS 序列和 BFS 序列都可能不唯一，当有多个邻接点且没规定访问次序时。考试若给了邻接矩阵或邻接表并规定"按编号从小到大"，序列才唯一。

## 最小生成树

| 术语 | 定义 |
|---|---|
| 生成树 | 连通图的极小连通子图，含全部 n 个顶点和恰好 n-1 条边 |
| 最小生成树 | 带权连通图中边权之和最小的生成树 |
| MST 的代价 | 最小生成树中所有边的权值之和 |

三条性质：最小生成树不一定唯一（有相同权值的边时），但代价唯一。若所有边权互不相同，MST 唯一。n 个顶点的生成树恰好 n-1 条边。

### Prim 算法

从顶点出发，逐步长成树。

```
1. 任选一个顶点加入集合 U
2. 在所有"一端在 U 内、另一端在 U 外"的边中，选权值最小的一条
3. 把该边及其 U 外的端点加入生成树
4. 重复 2 到 3，直到 U 包含全部 n 个顶点
```

时间 `O(n²)`，与边数无关，适合稠密图。辅助数组是 lowcost（U 到各顶点的最小边权）和 closest（对应的 U 内顶点）。

### Kruskal 算法

从边出发，避免成环。

```
1. 所有边按权值从小到大排序
2. 依次考察每条边：若两端点在当前森林中属于不同连通分量
   （加入后不成环），就加入生成树
3. 直到选够 n-1 条边
```

时间 `O(e log e)`，适合稀疏图。判定成环用并查集。

### 2025 年第 24 题

带权无向图 6 个顶点，题给的边表已按权值排好：

| 序号 | 边 | 权 | 序号 | 边 | 权 |
|---|---|---|---|---|---|
| 1 | (2,3) | 5 | 6 | (4,5) | 10 |
| 2 | (2,4) | 6 | 7 | (5,6) | 10 |
| 3 | (3,4) | 6 | 8 | (2,6) | 11 |
| 4 | (1,6) | 9 | 9 | (4,6) | 14 |
| 5 | (1,5) | 10 | 10 | (1,2) | 20 |

Kruskal 过程，6 个顶点需选 5 条边：

| 步骤 | 考察的边 | 权 | 是否加入 | 依据 | 已选 |
|---|---|---|---|---|---|
| 1 | (2,3) | 5 | 加入 | 2、3 不同分量 | 1 |
| 2 | (2,4) | 6 | 加入 | 2、4 不同分量 | 2 |
| 3 | (3,4) | 6 | 舍去 | 3、4 已连通，加入会成环 | 2 |
| 4 | (1,6) | 9 | 加入 | 1、6 不同分量 | 3 |
| 5 | (1,5) | 10 | 加入 | 1、5 不同分量 | 4 |
| 6 | (4,5) | 10 | 加入 | 4、5 不同分量 | 5 完成 |

选的 5 条边是 `(2,3)=5`、`(2,4)=6`、`(1,6)=9`、`(1,5)=10`、`(4,5)=10`。

代价 = 5 + 6 + 9 + 10 + 10 = 40。

过程图用文字描述：
```
步骤1: 加入 (2,3)=5       分量 {2,3} {1} {4} {5} {6}
步骤2: 加入 (2,4)=6       分量 {2,3,4} {1} {5} {6}
步骤3: (3,4) 端点已同属 {2,3,4}，成环，舍去
步骤4: 加入 (1,6)=9       分量 {2,3,4} {1,6} {5}
步骤5: 加入 (1,5)=10      分量 {2,3,4} {1,5,6}
步骤6: 加入 (4,5)=10      分量 {1,2,3,4,5,6} 连通，完成
```

## 拓扑排序

| 术语 | 定义 |
|---|---|
| AOV 网 | 用顶点表示活动、用弧表示优先关系的有向无环图 |
| 前驱后继 | 有弧 `<vi, vj>` 时 vi 是 vj 的前驱 |
| 拓扑排序 | 把所有顶点排成线性序列，使所有弧都从前指向后 |
| 拓扑序列 | 拓扑排序的结果 |

几个关键结论：拓扑序列可能不唯一，当同时存在多个入度为 0 的顶点时。有环的有向图不存在拓扑序列，所以拓扑排序能判环。拓扑序列的第一个顶点必然是入度为 0 的顶点。

### 算法（Kahn）

```
1. 统计所有顶点入度，建立入度表
2. 所有入度为 0 的顶点入队
3. 从队中取一个顶点 v，输出它
4. 把 v 的所有后继入度减 1；减到 0 的入队
5. 重复 3 到 4，直到队列为空
6. 若输出的顶点数小于 n，说明有环
```

邻接表存储时时间 `O(n + e)`。

### 例题

顶点 1 到 5，弧为 `<1,2>`、`<1,3>`、`<2,4>`、`<3,4>`、`<4,5>`。

入度表：`ID(1)=0, ID(2)=1, ID(3)=1, ID(4)=2, ID(5)=1`。

```
初始入度 0：{1}
出 1，输出 1；2 的入度 1→0 入队；3 的入度 1→0 入队
队列 {2, 3}
出 2，输出 2；4 的入度 2→1
出 3，输出 3；4 的入度 1→0 入队
出 4，输出 4；5 的入度 1→0 入队
出 5，输出 5
```
一个合法序列是 1, 2, 3, 4, 5。若先出 3 再出 2，得 1, 3, 2, 4, 5，也合法。

## 单源最短路径

| 术语 | 定义 |
|---|---|
| 源点 | 路径的起点 |
| 终点 | 路径的终点 |
| 单源最短路径 | 从源点到其余各顶点的最短路径 |
| Dijkstra | 按路径长度递增的次序逐个产生最短路径 |

算法是贪心的：
```
1. S 为已确定最短路径的顶点集，初始 S = {源点 v0}
2. dist[i] 初值 = 边 (v0, vi) 的权，无边则 ∞
3. 从 V-S 中选 dist 最小的顶点 u，加入 S
4. 用 u 作中转更新 V-S 中的 dist：
   若 dist[u] + w(u,v) < dist[v]，则更新
5. 重复 3 到 4，直到 S 含全部顶点
```

两个必背要点。Dijkstra 不能处理负权边，因为贪心假设"已确定的路径不会再变短"，负权会破坏这个假设，这时要用 Bellman-Ford 或 Floyd。时间复杂度 `O(n²)`。

### 用 2025 年那张图算一遍

顶点 1 到 6，边同上，求从顶点 1 出发到各顶点的最短距离。

| 步骤 | S | 选出的 u | dist[B] | dist[C] | dist[D] | dist[E] | 本轮更新 |
|---|---|---|---|---|---|---|---|
| 初始 | {1} | — | 20 | ∞ | ∞ | 10 | 9 |
| 1 | {1} | 6（dist=9） | 20 | ∞ | ∞ | 10 | 9 |
| 2 | {1,6} | 5（dist=10） | 20 | ∞ | 20 | 10 | 9 |
| 3 | {1,6,5} | 2（dist=20） | 20 | 25 | 20 | 10 | 9 |
| 4 | {1,6,5,2} | 4（dist=20） | 20 | 25 | 20 | 10 | 9 |
| 5 | 全部 | 3（dist=25） | 20 | 25 | 20 | 10 | 9 |

结果为 `dist = {1:0, 2:20, 3:25, 4:20, 5:10, 6:9}`。

关键更新：加入 6 后 `dist[5] = min(10, 9+10) = 10`；加入 5 后 `dist[4] = 10+10 = 20`；加入 2 后 `dist[3] = 20+5 = 25`；加入 4 后 `dist[3] = min(25, 20+6) = 25`，不变。

## 考前十分钟

1. 无向完全图边数 `n(n-1)/2`，有向完全图弧数 `n(n-1)`。
2. 连通 n 个顶点至少 n-1 条边，强连通至少 n 条弧。
3. 无向图 `Σ度 = 2e`，度之和必为偶数。有向图 `Σ入度 = Σ出度 = e`。
4. `TD(v) = ID(v) + OD(v)`。
5. 邻接矩阵无向图对称；有向图第 i 行和是出度、第 i 列和是入度。
6. 邻接矩阵 O(n²) 适合稠密图，邻接表 O(n+e) 适合稀疏图。
7. 无向图邻接表有 2e 个边结点，有向图 e 个。
8. DFS 用栈，BFS 用队列。
9. DFS 和 BFS 的时间：邻接矩阵 O(n²)，邻接表 O(n+e)。
10. 生成树 n 个顶点、n-1 条边。
11. Prim 是加点法，`O(n²)`，适合稠密图；Kruskal 是加边法，`O(e log e)`，适合稀疏图。
12. MST 不唯一但代价唯一；边权互不相同则唯一。
13. Prim 与 Kruskal 的代价必相同。
14. 拓扑排序第一个顶点必是入度为 0 的顶点；输出顶点数小于 n 说明有环。
15. Dijkstra 不能处理负权边，时间 `O(n²)`。
16. 路径长度是边的数目。

**B-7**
原因：Dijkstra 的核心是贪心，一旦某顶点被选入 S（已确定最短路径集合），就认为它的最短路径定死了，以后不会再缩短。这个假设成立的前提是"路径上再加边只会让长度增加"，即所有边权非负。有负权边时，绕远路反而可能得到更短的总长，已确定的距离可能被后续路径推翻，贪心的正确性被破坏。

反例：4 个顶点，源点 A。
```
A→B 权 1
A→C 权 5
C→D 权 -4
D→B 权 -3
```
真实最短路径：A→B 直接是 1，经 A→C→D→B 是 5 + (-4) + (-3) = -2，更短。A→C 是 5。A→D 是 5 + (-4) = 1。

Dijkstra 执行：初始 `dist = [A:0, B:1, C:5, D:∞]`。
选 B（dist=1），标记确定，但真实的 dist[B] 是 -2，已经错了。
选 C（dist=5），更新 D 为 5+(-4) = 1。
选 D（dist=1），更新 B 为 1+(-3) = -2，小于 1，但 B 已被标记为"已确定"，Dijkstra 不会回头修正。

所以 Dijkstra 给出 dist[B] = 1，错，应为 -2。必须改用 Bellman-Ford 或 Floyd。

```c
/* 遍历每个顶点的链表，链表长度即该顶点的度；所有长度之和除以 2 是边数。 */
void statAL(ALGraph *G, int deg[], int *edgeCount) {
    int i, sum = 0;
    ArcNode *p;
    for (i = 0; i < G->n; i++) {
        deg[i] = 0;
        for (p = G->vertices[i].firstarc; p != NULL; p = p->nextarc)
            deg[i]++;
        sum += deg[i];
    }
    *edgeCount = sum / 2;    // 无向图每条边被数两次
}
```

**C-3**
```c
/* Kahn 算法：统计入度，入度为 0 的入队，反复出队输出、
   把后继入度减 1，减到 0 就入队。
   最终输出顶点数小于 n 说明有环。 */
int hasCycle(ALGraph *G) {
    int indeg[MAXV] = {0}, q[MAXV], front = 0, rear = 0;
    int i, count = 0;
    ArcNode *p;

    for (i = 0; i < G->n; i++)
        for (p = G->vertices[i].firstarc; p != NULL; p = p->nextarc)
            indeg[p->adjvex]++;

    for (i = 0; i < G->n; i++)
        if (indeg[i] == 0) q[rear++] = i;

    while (front != rear) {
        int u = q[front++];
        count++;
        for (p = G->vertices[u].firstarc; p != NULL; p = p->nextarc) {
            if (--indeg[p->adjvex] == 0)
                q[rear++] = p->adjvex;
        }
    }
    return (count == G->n) ? 0 : 1;    // 1 表示有环
}
```
时间 O(n + e)。

```c
            }
    }
}
```
若要统计连通分量个数，外层再套一个循环，对每个未访问顶点调用一次 BFS，每次计数加一。

**C-5**
（1）

| 维度 | 邻接矩阵 | 邻接表 |
|---|---|---|
| 空间 | O(n²)，与边数无关 | O(n+e) |
| 判 (i,j) 是否有边 | O(1) | O(deg(i)) |
| 遍历某顶点邻接点 | O(n) | O(deg(i))，更高效 |
| 增删边 | O(1) | O(1)（头插） |
| 表示唯一性 | 唯一 | 不唯一，依赖插入次序 |
| 适合 | 稠密图 | 稀疏图 |

（2）无向边 `(i,j)` 与 `(j,i)` 是同一条边，邻接矩阵中 `A[i][j] = A[j][i]`，关于主对角线对称。
有向图中弧 `<i,j>` 存在不代表 `<j,i>` 存在，比如 `1→2` 存在而 `2→1` 不存在，此时 `A[1][2]=1` 但 `A[2][1]=0`，不对称。只有每个顶点入度等于出度且对应弧成对出现的有向图，邻接矩阵才可能对称。

**C-6**
（1）Prim 是从一个顶点出发，每次在"已在树中"与"尚未加入"之间的所有边里选权值最小的一条，把对应顶点并进来，直到含全部 n 个顶点。
Kruskal 是把所有边按权升序排列，依次考察，若两端点当前分属不同连通分量（加入不成环）就加入，直到选够 n-1 条。

（2）Prim 时间 `O(n²)`，和顶点数关系大，适合稠密图。Kruskal 是 `O(e log e)`，和边数关系大，适合稀疏图。

（3）最小生成树是所有生成树中代价最小的那个，它的代价由图的边权唯一确定，是所有生成树代价的下确界。Prim 和 Kruskal 都是正确的 MST 算法，都有基于"切割性质"和"环性质"的严格最优性证明，因此必然都达到这个下确界，代价相等。
树形可能不同（有等权边时），但代价必相同，这也是用另一种算法验算的依据。

**C-7**
（1）拓扑排序是把有向无环图的所有顶点排成线性序列，使任意一条弧 `<u,v>` 中 u 都排在 v 之前。
实际应用很多：课程安排的先修关系、工程施工顺序、编译时的模块依赖、项目管理任务调度、Excel 公式的依赖计算、makefile 的构建顺序。

（2）设环为 `v₁ → v₂ → … → vₖ → v₁`。拓扑序列要求 v₁ 在 v₂ 前、v₂ 在 v₃ 前、……、vₖ 在 v₁ 前。串起来得到"v₁ 在 v₁ 之前"，逻辑矛盾。所以有环必无拓扑序列。
反过来，若算法输出的顶点数小于 n，说明剩下的顶点互相阻塞（每个入度都至少 1），它们必然构成环。

（3）不唯一。只有当每一步都恰好只有一个入度为 0 的顶点时，拓扑序列才唯一。
比如 `1→2→3→4` 一条链，每步入度 0 的顶点唯一，序列唯一，就是 1,2,3,4。
而 `1→2`、`1→3` 这种，输出 1 后 2 和 3 入度都变 0，二者可互换，有两个序列 `1,2,3` 和 `1,3,2`。
