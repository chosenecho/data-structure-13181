## 栈是什么

栈是只能在表的一端做插入和删除的线性表。允许操作的那端叫栈顶，另一端叫栈底，固定不动。插入叫入栈，删除叫出栈。

特性是后进先出。最后进去的最先出来。

栈底的作用只是标记"这端不能动"，用来确定存储空间的边界。

| 术语 | 含义 |
|---|---|
| 栈的容量 | 最多能装几个元素 |
| 空栈 | 不含任何元素 |
| 栈满 | 元素个数达到容量 |
| 栈顶元素 | 最近一次入栈、还没出栈的那个 |
| 出栈序列 | 元素出栈的先后次序 |
| 顺序栈 | 用数组实现 |
| 链式栈 | 用链表实现，通常在表头插入删除 |

## 顺序栈

```c
#define maxSize 100
typedef int ELEMType;
typedef struct {
    ELEMType elem[maxSize];
    int top;
} SeqStack;
```

top 的约定有两种，考试要先看清题目用哪种。

| 约定 | 初始化 | 栈空 | 栈满 | 入栈 | 出栈 |
|---|---|---|---|---|---|
| A：top 指栈顶元素 | `top = -1` | `top == -1` | `top == maxSize-1` | `elem[++top] = x` | `x = elem[top--]` |
| B：top 指下一空位 | `top = 0` | `top == 0` | `top == maxSize` | `elem[top++] = x` | `x = elem[--top]` |

教材（辛运帏版）用约定 A。答题时如果题目没说明，先按 A 答，并在步骤里写明你的约定。

基本操作，约定 A：

```c
void initStack(SeqStack *s) { s->top = -1; }
int isEmpty(SeqStack *s) { return (s->top == -1); }
int isFull(SeqStack *s) { return (s->top == maxSize - 1); }

int push(SeqStack *s, ELEMType x) {
    if (s->top == maxSize - 1) return 0;      // 先判满
    s->elem[++s->top] = x;
    return 1;
}

int pop(SeqStack *s, ELEMType *x) {
    if (s->top == -1) return 0;               // 先判空
    *x = s->elem[s->top--];
    return 1;
}

int getTop(SeqStack *s, ELEMType *x) {
    if (s->top == -1) return 0;
    *x = s->elem[s->top];
    return 1;
}
```

入栈先判满，出栈先判空。这两句在算法阅读题的填空里几乎年年在。

## 链式栈

用单链表实现，栈顶在表头，因为表头插入删除是 O(1)。所以链式栈的 push 就是头插，pop 就是删首结点。

```c
typedef struct snode {
    ELEMType data;
    struct snode *next;
} SNode;
typedef SNode *LinkStack;

int pushLink(LinkStack *top, ELEMType x) {
    SNode *s = (SNode *)malloc(sizeof(SNode));
    if (s == NULL) return 0;
    s->data = x;
    s->next = *top;
    *top = s;
    return 1;
}

int popLink(LinkStack *top, ELEMType *x) {
    SNode *p;
    if (*top == NULL) return 0;
    p = *top;
    *x = p->data;
    *top = p->next;
    free(p);
    return 1;
}
```

顺序栈和链式栈对比：

| | 顺序栈 | 链式栈 |
|---|---|---|
| 栈满 | 存在，`top == maxSize-1` | 不存在，除非内存耗尽 |
| 栈空 | `top == -1` | `top == NULL` |
| 空间 | 固定，可能溢出 | 动态，不溢出 |
| push/pop | 都是 O(1) | 都是 O(1) |
| 额外开销 | 无 | 每结点一个指针 |

## 出栈序列

这是选择题里最难拿的一分。

原理是这样：如果进栈顺序固定为 a₁ 到 aₙ，那么出栈序列里若某个元素排在另一个之前，而它在进栈顺序里排得更后，说明中间被它压住的元素必须已经出栈了。

考场上更实用的办法是模拟：按进栈顺序依次压栈，压的过程可以随时弹出若干次。用题目给的出栈序列去核对，能一路核对到底就合法。

具体操作：对出栈序列的每个元素 y，如果栈顶就是 y 就弹出；否则把还没入栈的元素依次压进去，直到压入 y 再弹出；如果所有元素都压完了还没遇到 y，这个序列就不合法。

### 2025 年那道题

栈中有 a、b、c 三个元素（a 为栈底，c 为栈顶），元素 d 等待进栈，则可能的出栈序列是
A. d, a, c, b　B. c, a, d, b　C. b, d, a, c　D. c, b, d, a

当前栈自底向上是 a、b、c，栈顶是 c，d 还没进。

A：要输出 d，得先压入 d，栈变成 a,b,c,d（顶 d）。弹出 d 后栈顶是 c，下一个该输出 c，不是 a。错。

B：弹出 c 后栈顶是 b，该输出 b，不是 a。错。

C：要输出 b，必须先把 c 弹掉，但序列首位不是 c，矛盾。错。

D：弹 c（栈剩 a,b），弹 b（栈剩 a），压入 d 并弹出 d（栈剩 a），弹 a。合法。

答案 D。

### 合法序列总数

n 个不同元素依次进栈，可能的出栈序列总数是卡特兰数：

```
C(2n, n) / (n+1)
```

n=1 是 1，n=2 是 2，n=3 是 5，n=4 是 14，n=5 是 42。

n=3 那 5 种是 abc、acb、bac、bca、cba。注意 cab 不合法，因为 c 出来时 a、b 都被它压着。

### 输入受限和输出受限的双端队列

双端队列两端都能插入和删除。输入受限的双端队列只允许一端插入、两端都能删除。输出受限的两端都能插入、只允许一端删除。

这类结构的合法出栈序列比栈多，因为可以从两端出。

## 栈的三个应用

### 括号匹配

遇左括号入栈，遇右括号时若栈空就失败，否则弹栈顶看是否配对。扫完栈必须为空。

```c
int match(char *s) {
    SeqStack st; char ch;
    initStack(&st);
    while (*s != '\0') {
        if (*s=='(' || *s=='[' || *s=='{') {
            push(&st, *s);
        } else if (*s==')' || *s==']' || *s=='}') {
            if (isEmpty(&st)) return 0;
            pop(&st, &ch);
            if ((*s==')' && ch!='(') ||
                (*s==']' && ch!='[') ||
                (*s=='}' && ch!='{')) return 0;
        }
        s++;
    }
    return isEmpty(&st);
}
```

时间 O(n)，空间 O(n)。

### 中缀转后缀

运算符优先级：括号入栈时最高，乘除 5，加减 4，栈内左括号 1。

算法是调度场那一套：从左往右扫，操作数直接输出；左括号入栈；右括号就不断弹栈输出直到弹出左括号；运算符则先把栈里优先级不低于它的都弹出来，再把它入栈；扫完后把栈里剩下的全弹出。

例：`A + B * C - D / E` 转成 `A B C * + D E / -`。

带括号的：`(A + B) * (C - D)` 转成 `A B + C D - *`。

手算速查：

| 中缀 | 后缀 |
|---|---|
| `A+B` | `AB+` |
| `A+B*C` | `ABC*+` |
| `(A+B)*C` | `AB+C*` |
| `A*(B+C)-D` | `ABC+*D-` |
| `A-B+C` | `AB-C+`（左结合，同级从左到右） |
| `A/B*C` | `AB/C*` |

### 后缀求值

操作数入栈，遇运算符连续出栈两次，先出的是右操作数，后出的是左操作数，算出结果再入栈。扫完栈里剩的那个数就是结果。

最容易错的就是出栈顺序。`a b -` 是 a 减 b，不是 b 减 a，因为先弹出的是 b。

例：`3 4 + 5 *` 是 (3+4)×5 = 35。`8 3 2 - *` 是 8×(3-2) = 8。

## 队列

队列只能在一端插入、另一端删除。插入那端叫队尾，删除那端叫队头。特性是先进先出。

头删尾插，四个字别记反。

| 术语 | 含义 |
|---|---|
| 队头 front | 允许删除的一端 |
| 队尾 rear | 允许插入的一端 |
| 入队 | 在队尾插入 |
| 出队 | 在队头删除 |
| 队列长度 | 当前元素个数 |

## 循环队列

普通顺序队列有个假溢出的问题：随着出队，front 不断后移，前面空出的位置再也用不上，等到 rear 到数组末尾，明明前面还有空位却入不了队。

解决办法是把数组首尾接起来，让 rear 和 front 用取模循环移动。

```c
#define maxSize 100
typedef int ELEMType;
typedef struct {
    ELEMType elem[maxSize];
    int front;   // 队头元素下标
    int rear;    // 队尾元素的下一个位置
} CirQueue;
```

### 判空判满

麻烦在于循环队列里 `front == rear` 既可能是空，也可能是满（绕了一圈回来），没法区分。

三种方案：

| 方案 | 判空 | 判满 | 元素个数 | 说明 |
|---|---|---|---|---|
| 牺牲一个单元（最常用） | `front == rear` | `(rear+1) % maxSize == front` | `(rear-front+maxSize) % maxSize` | 实际最多存 maxSize-1 个 |
| 增设 size 计数 | `size == 0` | `size == maxSize` | `size` | 能存满 maxSize 个 |
| 增设 tag 标志 | `front==rear && tag==0` | `front==rear && tag==1` | `(rear-front+maxSize)%maxSize` | 出队置 0，入队置 1 |

考试默认方案一。判满 `(rear+1) % maxSize == front`，队列最多存 maxSize-1 个元素。这个"少一个"是填空的高频陷阱。

### 基本操作

```c
void initQueue(CirQueue *q) { q->front = q->rear = 0; }
int isEmpty(CirQueue *q) { return (q->front == q->rear); }
int isFull(CirQueue *q) { return ((q->rear + 1) % maxSize == q->front); }

int enQueue(CirQueue *q, ELEMType x) {
    if ((q->rear + 1) % maxSize == q->front) return 0;  // 先判满
    q->elem[q->rear] = x;
    q->rear = (q->rear + 1) % maxSize;
    return 1;
}

int deQueue(CirQueue *q, ELEMType *x) {
    if (q->front == q->rear) return 0;                  // 先判空
    *x = q->elem[q->front];
    q->front = (q->front + 1) % maxSize;
    return 1;
}

int queueLength(CirQueue *q) {
    return (q->rear - q->front + maxSize) % maxSize;
}
```

为什么要先加 maxSize 再取模？因为 C 语言的 `%` 对负数返回负数，`-3 % 10` 还是 `-3`，加上 maxSize 才能保证结果为正。

### 两个小算题

maxSize = 50，front = 30，rear = 10，队列里几个元素？`(10-30+50) % 50 = 30` 个。

maxSize = 20，front = 15，队列里有 8 个元素，rear 是多少？`(15+8) % 20 = 3`。

## 链式队列

用单链表实现，队头在表头（删除），队尾在表尾（插入）。需要两个指针，front 和 rear，通常还带一个头结点。

判空是 `front == rear`（都指头结点）或 `front->next == NULL`。不存在队满。

```c
typedef struct qnode {
    ELEMType data;
    struct qnode *next;
} QNode;
typedef struct {
    QNode *front, *rear;
} LinkQueue;

int enQueue(LinkQueue *q, ELEMType x) {
    QNode *s = (QNode *)malloc(sizeof(QNode));
    if (s == NULL) return 0;
    s->data = x;
    s->next = NULL;
    q->rear->next = s;
    q->rear = s;
    return 1;
}

int deQueue(LinkQueue *q, ELEMType *x) {
    QNode *p;
    if (q->front == q->rear) return 0;
    p = q->front->next;
    *x = p->data;
    q->front->next = p->next;
    if (q->rear == p) q->rear = q->front;  // 删的是唯一结点，尾指针要回退
    free(p);
    return 1;
}
```

那句 `if (q->rear == p)` 是链式队列的经典陷阱。删掉最后一个结点后队列变空，rear 会悬挂在已释放的内存上，以后入队写 `q->rear->next = s` 就写到已释放的地方去了。必须把 rear 重置回 front。

## 栈和队列对比

| | 栈 | 队列 |
|---|---|---|
| 特性 | 后进先出 | 先进先出 |
| 插入端 | 栈顶 | 队尾 |
| 删除端 | 栈顶，同一端 | 队头，不同端 |
| 典型应用 | 括号匹配、表达式转换与求值、递归、DFS、函数调用 | 层序遍历、BFS、缓冲区、打印任务 |
| 顺序实现的关键问题 | 栈满判定 | 假溢出，要用循环队列 |
| 链式实现的插入端 | 表头 | 表尾 |

## 对顶栈

两个栈共用一个数组，分别从两端往中间长。

```c
#define maxSize 100
typedef struct {
    ELEMType elem[maxSize];
    int lefttop;    // 左栈栈顶，从 0 开始向右长
    int righttop;   // 右栈栈顶，从 maxSize-1 开始向左长
} SeqTopStack;
```

判空：左栈 `lefttop == -1`（或按约定是 0），右栈 `righttop == maxSize`（或按约定是 maxSize-1）。

判满：两栈相邻时数组已满，即 `lefttop + 1 == righttop`。

优势是空间共享，只有两个栈的元素总数达到 maxSize 才溢出，比两个独立栈各自 maxSize 更省。

### 2025 年真题第 27 题

```c
int fun(SeqTopStack *mys, ELEMType *x, int flag) {
    if ((flag == -1 && mys->lefttop == 0) || (flag == 1 && mys->righttop == maxSize - 1)) {
        printf("栈空\n");
        return 0;
    } else {
        if (flag == -1) {
            *x = mys->element[--mys->lefttop];
            return 1;
        } else if (flag == 1) {
            *x = mys->element[++mys->righttop];
            return 1;
        }
    }
}
```

第一问，fun 的功能是按 flag 指定的栈做出栈操作，把弹出的元素通过 x 返回。flag 为 -1 时从左栈出，为 1 时从右栈出。栈空时打印提示返回 0，成功返回 1。

第二问，flag 是栈的选择标志位。这是两个栈共享一个数组的结构，同一个函数要服务两个栈，必须靠参数区分目标。取 -1 表示左栈，取 1 表示右栈。

有一点要注意：题干里判空用的是 `lefttop == 0` 和 `righttop == maxSize - 1`，而出栈用的是先变指针再取值（`--lefttop` 和 `++righttop`），说明这套约定是 top 指向栈顶元素的下一空位，左栈初始 0，右栈初始 maxSize-1。判空条件和这个约定是自洽的。考试时要按题干给出的约定判断，别套自己背的 -1 和 maxSize。

## 考前十分钟

1. 栈只能在栈顶插入删除，后进先出。队列队尾插入、队头删除，先进先出。
2. 顺序栈约定 A：top 初始 -1，空为 `top == -1`，满为 `top == maxSize-1`。
3. 顺序栈约定 B：top 初始 0，空为 `top == 0`，满为 `top == maxSize`。
4. 入栈先判满，出栈先判空。
5. 链式栈栈顶在表头，push 就是头插，pop 就是删首结点，不存在栈满。
6. n 个元素的合法出栈序列数是卡特兰数：1、2、5、14、42。
7. 出栈序列用栈模拟，一路走通才合法。
8. 中缀转后缀：操作数直接输出，左括号入栈，右括号弹到左括号，运算符按优先级弹栈。
9. 后缀求值：操作数入栈，运算符出栈两次，先出的是右操作数。
10. 循环队列判空 `front==rear`，判满 `(rear+1)%maxSize==front`，元素个数 `(rear-front+maxSize)%maxSize`。
11. 循环队列最多存 maxSize-1 个元素。
12. 链式队列删最后一个结点时必须重置 rear。
13. 假溢出是普通顺序队列的问题，循环队列解决它。
14. 对顶栈两栈共用数组，共同判满 `lefttop + 1 == righttop`。

## 练习

### A 组

**A-1** 栈和队列的共同点是
A. 都是先进先出 B. 都是先进后出 C. 都只允许在端点处插入和删除元素 D. 都没有共同点

**A-2** 栈的特点是
A. 先进先出 B. 后进先出 C. 随机存取 D. 顺序存取

**A-3** 队列的插入操作是在
A. 队头 B. 队尾 C. 队头和队尾都能 D. 任意位置

**A-4** 若进栈序列为 1,2,3,4，则下列不可能得到的出栈序列是
A. 1,2,3,4 B. 4,3,2,1 C. 1,4,2,3 D. 3,2,4,1

**A-5** 3 个不同元素依次进栈，可能的出栈序列共有
A. 3 种 B. 4 种 C. 5 种 D. 6 种

A. `top == 0` B. `top == -1` C. `top == maxSize` D. `top == maxSize-1`

**A-7** 设顺序栈 top 初值为 -1，容量为 n，栈满的条件是
A. `top == n` B. `top == n-1` C. `top == 0` D. `top == -1`

**A-8** 循环队列（牺牲一个单元）判满的条件是（M 为数组长度）
A. `rear == front` B. `(rear+1) % M == front` C. `rear+1 == front` D. `rear == 0`

**B-6**
改进之处：普通顺序队列有假溢出：随着出队，队头指针后移，前面空出的单元再也用不上，等到 rear 到达数组末尾，尽管前面有空位也入不了队。循环队列把数组看成首尾相接的环，让 front 和 rear 通过取模循环移动，复用已出队的位置，消除假溢出。

为什么判空判满不能用同一条件：循环队列里 `front == rear` 有两种可能：队列为空（元素全出队，front 追上 rear），或者队列为满（rear 绕一圈追上 front）。两者状态完全相同，光凭 `front == rear` 分不出来。必须额外引入手段（牺牲一个单元、增设 size、增设 tag）才能把空和满分开。

### C 组

**C-1**
```c
/* 遇左括号入栈；遇右括号，栈空说明右括号多余，失败；
   否则弹栈顶检查是否配对；不配对失败。扫完栈必须为空。 */
int matchBracket(char *s) {
    SeqStack st;
    char top, ch;
    initStack(&st);
    while ((ch = *s++) != '\0') {
        if (ch == '(' || ch == '[' || ch == '{') {
            push(&st, ch);
        } else if (ch == ')' || ch == ']' || ch == '}') {
            if (isEmpty(&st)) return 0;
            pop(&st, &top);
            if ((ch == ')' && top != '(') ||
                (ch == ']' && top != '[') ||
                (ch == '}' && top != '{')) return 0;
        }
    }
    return isEmpty(&st);
}
```
时间 O(n)，空间 O(n)。

**C-2**
```c
/* 1) 操作数直接输出
   2) 左括号入栈
   3) 右括号弹栈输出直到遇左括号，左括号丢弃
   4) 运算符：栈非空且栈顶不是左括号且栈顶优先级不低于它时反复弹栈输出，
      再把它入栈
   5) 扫完把栈里剩下的全弹出 */
int prio(char op) {
    if (op == '*' || op == '/') return 5;
    if (op == '+' || op == '-') return 4;
    if (op == '(') return 1;
    return 0;
}

void infixToPostfix(char *infix, char *postfix) {
    SeqStack st;
    char ch, top;
    int k = 0;
    initStack(&st);
    while ((ch = *infix++) != '#' && ch != '\0') {
        if (ch >= '0' && ch <= '9') {
            postfix[k++] = ch;
        } else if (ch == '(') {
            push(&st, ch);
        } else if (ch == ')') {
            while (!isEmpty(&st)) {
                pop(&st, &top);
                if (top == '(') break;
                postfix[k++] = top;
            }
        } else {
            while (!isEmpty(&st) && getTop(&st, &top) && prio(top) >= prio(ch)) {
                pop(&st, &top);
                postfix[k++] = top;
            }
            push(&st, ch);
        }
    }
    while (!isEmpty(&st)) { pop(&st, &top); postfix[k++] = top; }
    postfix[k] = '\0';
}
```

**C-3**
```c
/* 操作数入栈；运算符连续出栈两次，先出的是右操作数 b，
   后出的是左操作数 a，算 a op b 再入栈。扫完栈里唯一的数即结果。 */
int evalPostfix(char *s) {
    SeqStack st;
    int op1, op2, r;
    char ch;
    initStack(&st);
    while ((ch = *s++) != '#' && ch != '\0') {
        if (ch >= '0' && ch <= '9') {
            push(&st, ch - '0');
        } else {
            pop(&st, &op2);
            pop(&st, &op1);
            switch (ch) {
                case '+': r = op1 + op2; break;
                case '-': r = op1 - op2; break;
                case '*': r = op1 * op2; break;
                case '/': r = op1 / op2; break;
            }
            push(&st, r);
        }
    }
    pop(&st, &r);
    return r;
}
```
两个 pop 的顺序不能反。

**C-4**
```c
/* 两个栈 s1 入队栈、s2 出队栈。
   入队直接压 s1；出队若 s2 非空直接弹 s2，若 s2 空则把 s1 全部倒进 s2 再弹。
   每个元素最多被移动两次，出队均摊 O(1)。 */
void enQueueSim(SeqStack *s1, ELEMType x) {
    push(s1, x);
}

int deQueueSim(SeqStack *s1, SeqStack *s2, ELEMType *x) {
    ELEMType t;
    if (isEmpty(s1) && isEmpty(s2)) return 0;
    if (isEmpty(s2)) {
        while (!isEmpty(s1)) {
            pop(s1, &t);
            push(s2, t);
        }
    }
    pop(s2, x);
    return 1;
}
```

**C-5**
（1）按 top 指向栈顶元素下一空位的约定（左栈初始 0，右栈初始 maxSize-1）：
- 左栈空：`lefttop == 0`
- 右栈空：`righttop == maxSize - 1`
- 整个数组已满：`lefttop == righttop`（两者相邻无空位）
若约定 top 指向栈顶元素本身（初始 -1 和 maxSize），判满条件变为 `lefttop + 1 == righttop`。答题时必须先声明约定。

（2）左栈入栈：
```c

mys->element[lefttop++] = x;
```

（3）两个独立栈各需 maxSize 空间，最坏共 2×maxSize。共享一个数组只需 maxSize，且只有两栈元素总数达到 maxSize 才溢出。对于一个可能很深、另一个很浅的场景，空间利用率明显提升。

**C-6**
栈是操作受限的线性表，只允许在表的一端（栈顶）插入删除，另一端（栈底）固定。元素进出遵循后进先出，最后入栈的最先出栈。

栈空判定：顺序栈（top 指栈顶元素、初值 -1）为 `top == -1`，即栈顶指针与栈底指针重合；链式栈（top 为栈顶指针）为 `top == NULL`（无头结点）或 `top->next == NULL`（带头结点）。

**C-7**
（1）长度公式 `len = (rear - front + m) % m`。
加 m 再取模是因为 `rear < front` 时 `rear - front` 为负，而 C 语言的 `%` 对负数仍返回负数，必须先加 m 变正。
不同教材公式略异是因为 front 和 rear 的约定不同：有的 front 指队头元素、rear 指队尾元素的下一位置（教材主流）；有的 front 指队头元素的前一位置、rear 指队尾元素；有的直接用 size 计数，公式就是 size。看到公式不同先看清指针定义。

（2）两种方案：
方案一，增设 size 计数器，入队 size++、出队 size--，判空 `size == 0`、判满 `size == m`。
方案二，增设 tag 标志，出队成功置 0、入队成功置 1，判空 `front == rear && tag == 0`、判满 `front == rear && tag == 1`。
第三种可选：数组开成 m+1 长，对外宣称容量 m，本质等价于牺牲一个单元。

（2）flag 是栈的选择标识位，用来指定本次操作作用于哪个栈。因为两个栈共用一套存储结构和同一个函数，必须靠参数区分目标栈。取 -1 表示左栈，取 1 表示右栈。

**D-4**
（1）队空 `front == rear`，队满 `(rear+1) % maxSize == front`。
（2）长度 `(rear - front + maxSize) % maxSize`。
（3）最多 maxSize - 1 个。这是高频填空陷阱，别答 maxSize。

**D-5**
功能：带头结点链式队列的出队操作，把队头元素通过 x 返回，队空返回 0，成功返回 1。
