# 第 5 章 树与二叉树

这一章 25 分上下，是全书分值最高的一章，五种题型全考。2025 年那份卷子在这里出了两道选择、一道填空、两道解答、一道算法阅读。

有三块必须死磕。二叉树的性质计算，考 `n₀ = n₂ + 1` 和层数结点数，选择题每次都出。由两个遍历序列还原二叉树，解答题几乎必考，一画错就是六分没了。哈夫曼树和 WPL，解答题的另一半。

顺手提一句，第 5 题那道"第 i 层最多几个结点"有陷阱。题目给的是 `i ≥ 0`，层数从 0 起算，答案就该是 `2^i`；要是从 1 起算，才是 `2^(i-1)`。很多资料按后者背，看到 `i ≥ 0` 也没反应过来。

## 树的术语

树的递归定义：n（n ≥ 0）个结点的有限集合，n = 0 是空树；n > 0 时有且仅有一个根结点，其余结点分成 m 个互不相交的有限集，每个集合本身又是一棵树，称为根的子树。

术语表，填空爱考：

| 术语 | 定义 |
|---|---|
| 结点的度 | 该结点拥有的子树（孩子）个数 |
| 树的度 | 所有结点度的最大值 |
| 叶结点 | 度为 0 的结点 |
| 分支结点 | 度大于 0 的结点 |
| 层次 | 根在第 1 层，往下推 |
| 树的深度（高度） | 结点的最大层次数 |
| 路径 | 从一结点到另一结点经过的结点序列 |
| 路径长度 | 路径上的边数，等于结点数减一 |
| 森林 | m 棵互不相交的树的集合 |

两条关系必须记住。结点总数等于所有结点的度之和加 1，因为除根外每个结点都是某结点的孩子，被数了一次度。结点总数也等于边数加 1。

### 度数和叶子数的关系

设 `nᵢ` 是度为 i 的结点个数，则
```
n₀ = 1 + n₂ + 2n₃ + 3n₄ + … + (k-1)nₖ
```
即 `n₀ = 1 + Σ(i-1)·nᵢ`，i ≥ 2。

二叉树特例：`n₀ = n₂ + 1`。

### 2025 年第 6 题

一棵二叉树只有度为 0 及度为 2 的结点，若叶结点数为 k，则结点总数为
A. k　B. 2k-1　C. k²　D. 2^k

由 `n₀ = n₂ + 1` 得 `k = n₂ + 1`，所以 `n₂ = k - 1`。总数是 `n₀ + n₂ = k + (k-1) = 2k - 1`。答案 B。

这类题套路固定：只有度为 0 和 2 的结点时，形状一定是完全二叉树，总结点必为奇数，等于 2k-1。

## 二叉树的性质

| 性质 | 内容 | 注意 |
|---|---|---|
| 1 | 第 i 层最多 `2^(i-1)` 个结点（i ≥ 1） | i 从 1 起 |
| 2 | 深度为 h 最多 `2^h - 1` 个结点 | 满二叉树 |
| 3 | `n₀ = n₂ + 1` | 最常考 |
| 4 | n 个结点的完全二叉树深度 `h = ⌊log₂n⌋ + 1` | 也写作 `⌈log₂(n+1)⌉` |
| 5 | 完全二叉树编号 1..n：父 `⌊i/2⌋`，左孩子 `2i`，右孩子 `2i+1` | `2i > n` 无左孩子 |

### 2025 年第 5 题

在二叉树的第 i（i ≥ 0）层上，结点数最多为
A. 2i　B. 2^(i-1)　C. 2^i　D. 2^(i+1)

题目明确写 `i ≥ 0`，层数从 0 起算。第 0 层（根）有 1 个，即 2⁰；第 i 层最多 `2^i`。答案 C。

这是本章最阴的坑。层数从 1 起算时答案是 `2^(i-1)`，从 0 起算是 `2^i`。判据就是看题目给的取值范围，写 `i ≥ 1` 选前者，写 `i ≥ 0` 选后者。

### 完全二叉树深度

```
n = 18：⌊log₂18⌋ + 1 = 4 + 1 = 5
n = 100：⌊log₂100⌋ + 1 = 6 + 1 = 7
n = 1000：⌊log₂1000⌋ + 1 = 9 + 1 = 10
```

n = 100 的完全二叉树，结点 50 的父结点是 `⌊50/2⌋ = 25`，左孩子 100，右孩子 101 超过 n 所以没有。结点 51 的左孩子 102 超过 100，所以是叶子。因此叶子是 51 到 100，共 50 个。

## 满二叉树和完全二叉树

| | 满二叉树 | 完全二叉树 |
|---|---|---|
| 定义 | 每层都达到最大结点数 | 除最后一层外每层都满，最后一层结点靠左连续 |
| 结点数 | 必为 `2^h - 1`，奇数 | 任意 n |
| 关系 | 一定是完全二叉树 | 不一定满 |
| 编号 | 1 到 2^h-1，无空缺 | 1 到 n，中间无空缺 |

判断技巧：把结点按层序编号，若每个结点 i 的父是 ⌊i/2⌋，就是完全二叉树。

二叉树有五种基本形态：空树、只有根、只有左子树、只有右子树、左右都有。

n 个结点的二叉树形态数是卡特兰数：n=1 是 1，n=2 是 2，n=3 是 5，n=4 是 14，n=5 是 42。大纲样题出过"4 个结点的二叉树有几种树形"，答案 14 种。

## 存储结构

顺序存储用一维数组按层序编号放结点。完全二叉树完美贴合，一般二叉树必须补空结点占位，单支树时 n 个结点要 2^n 空间，极度浪费。所以顺序存储只适合完全二叉树。

二叉链表最常用：
```c
typedef int ELEMType;
typedef struct BNode {
    ELEMType data;
    struct BNode *left, *right;
} BinTNode;
typedef BinTNode *BTree;
```

n 个结点的二叉链表共有 2n 个指针域，其中 n-1 个用于指孩子，剩下
```
2n - (n - 1) = n + 1
```
个是空指针。这正是线索二叉树存在的前提。

三叉链表在二叉链表基础上加 parent 指针，便于找父结点，空间开销更大。

线索二叉树用 ltag 和 rtag 标记指针是孩子还是线索。`ltag = 0` 时 left 指左孩子，`ltag = 1` 时 left 指前驱；`rtag` 同理指后继。中序线索最常用，可以 O(1) 找中序后继，实现不靠栈的中序遍历。

## 二叉树的四种遍历

| 遍历 | 顺序 | 口诀 | 辅助结构 |
|---|---|---|---|
| 先序 | 根左右 | 根左右 | 栈或递归 |
| 中序 | 左根右 | 左根右 | 栈或递归 |
| 后序 | 左右根 | 左右根 | 栈或递归 |
| 层序 | 逐层，同层从左到右 | — | 队列 |

2025 年第 19 题：在层序遍历过程中，需要一个＿＿作为辅助结构来记录当前已经涉及但尚未遍历的结点。答案是队列。

递归实现三行：
```c
void PreOrder(BTree t) {          // 先序
    if (t != NULL) {
        visit(t);
        PreOrder(t->left);
        PreOrder(t->right);
    }
}

void InOrder(BTree t) {           // 中序
    if (t != NULL) {
        InOrder(t->left);
        visit(t);
        InOrder(t->right);
    }
}

void PostOrder(BTree t) {         // 后序
    if (t != NULL) {
        PostOrder(t->left);
        PostOrder(t->right);
        visit(t);
    }
}
```

一行记忆：visit 放在哪就是什么序。最前是先序，中间是中序，最后是后序。

中序非递归用栈，最重要的一段：
```c
void InOrder2(BTree t) {
    BTree stack[100]; int top = -1;
    BTree p = t;
    while (p != NULL || top != -1) {
        while (p != NULL) { stack[++top] = p; p = p->left; }  // 一路向左入栈
        if (top != -1) {
            p = stack[top--];
            visit(p);
            p = p->right;
        }
    }
}
```

层序遍历用队列：
```c
void LevelOrder(BTree t) {
    BTree q[100]; int front = 0, rear = 0;
    if (t != NULL) q[rear++] = t;
    while (front != rear) {
        BTree p = q[front++];
        visit(p);
        if (p->left  != NULL) q[rear++] = p->left;
        if (p->right != NULL) q[rear++] = p->right;
    }
}
```

## 由遍历序列还原二叉树

| 组合 | 能否唯一确定 | 依据 |
|---|---|---|
| 先序加中序 | 能 | 先序第一个是根，在中序中切分左右 |
| 后序加中序 | 能 | 后序最后一个是根，在中序中切分 |
| 层序加中序 | 能 | 层序第一个是根，在中序中切分 |
| 先序加后序 | 不能（单支树除外） | 分不清唯一的孩子在左还是在右 |

还原四步（先序加中序）：
```
1. 先序第 1 个元素是根
2. 在中序中找到根，左边是左子树的中序，右边是右子树的中序
3. 数左子树有几个元素 k，先序中根之后 k 个是左子树的先序，剩下的是右子树的先序
4. 对左右子树递归执行 1 到 3
```
后序加中序把"第 1 个"改成"最后一个"，第 3 步的"之后 k 个"改成"之前 k 个"。

### 2025 年第 23 题

中序为 `D, B, E, H, A, F, C, I, G`，后序为 `D, H, E, B, F, I, G, C, A`。画树，写先序。

第 1 层：后序最后是 A，根是 A。中序中 A 左边 `D B E H` 四个是左子树，右边 `F C I G` 四个是右子树。后序对应切分成 `D H E B` 和 `F I G C`。

左子树（中序 DB EH，后序 D H E B）：后序最后是 B，根是 B。中序中 B 左边 D，右边 `E H`。后序切分成 D 和 `H E`。
- D 单独，是叶子。
- 中序 EH、后序 HE，根是 E。中序中 E 左边空、右边 H，所以 E 无左孩子，右孩子是 H。

右子树（中序 F C I G，后序 F I G C）：后序最后是 C，根是 C。中序中 C 左边 F，右边 `I G`。
- F 单独，叶子。
- 中序 IG、后序 IG，根是 G。中序中 G 左边 I、右边空，所以 G 的左孩子是 I。

树形：
```
                A
             /     \
            B       C
           / \     / \
          D   E   F   G
               \     /
                H   I
```

先序（根左右）= A, B, D, E, H, C, F, G, I。

检查方法：用画出的树重写中序和后序，看是否和题目一致。中序应是 `D B E H A F C I G`，后序应是 `D H E B F I G C A`。三十秒的检查能救六分。

### 表达式树

叶子是操作数，内部结点是运算符。先序遍历得前缀表达式，中序得中缀（要加括号才准确），后序得后缀表达式。

例：`(a+b)*(c-d)` 的表达式树先序是 `* + a b - c d`，后序是 `a b + c d - *`。

## 树、森林与二叉树

### 树的三种存储结构

| 表示法 | 结构 | 特点 |
|---|---|---|
| 双亲表示法 | 数组，每结点存 data 加 parent 下标 | 找父 O(1)，找子 O(n) |
| 孩子表示法 | 数组加每结点的孩子链表 | 找子快，找父慢 |
| 孩子兄弟表示法 | 每结点 firstChild 加 nextSibling | 找子找兄弟都快，能把树转成二叉树 |

```c
typedef struct CSNode {
    ELEMType data;
    struct CSNode *firstChild;
    struct CSNode *nextSibling;
} CSNode, *CSTree;
```

### 树转二叉树

口诀：左孩子右兄弟。

树的根做二叉树的根。每个结点的第一个孩子做该结点的左孩子，每个结点的下一个兄弟做该结点的右孩子。

例：树 R 有孩子 A、B、C，A 有 D、E，C 有 F。

转换后：
```
        R
       /
      A
     / \
    D   B
     \   \
      E   C
         /
        F
```
逐条对一下：R 的第一个孩子 A 成了 R 的左孩子，R 没兄弟所以没右孩子。A 的第一个孩子 D 成了 A 的左孩子，A 的下一个兄弟 B 成了 A 的右孩子。B 没孩子所以没左孩子，B 的下一个兄弟 C 成了 B 的右孩子。D 没孩子，下一个兄弟 E 成了 D 的右孩子。E 没孩子没兄弟，是叶子。C 的第一个孩子 F 成了 C 的左孩子，C 没兄弟所以没右孩子。

### 森林转二叉树（2025 年第 22 题）

题目：简述将森林 `F = {T₁, T₂, …, Tₘ}` 转换为二叉树 `B = (root, LB, RB)` 的规则。

分三步答：

先把森林中每棵树分别转换为二叉树，用左孩子右兄弟规则。第一棵树 T₁ 的根作为整个二叉树的根 root。从第二棵起，后一棵树的根依次作为前一棵树根的右孩子，T₂ 的根是 T₁ 根的右孩子，T₃ 的根是 T₂ 根的右孩子，串成 root 的右子树链 RB。每棵树内部按其自身的左孩子右兄弟规则转成对应的左子树 LB。

一句话：树转二叉树用左孩子右兄弟，森林转二叉树再把各树根用右链串起来。

### 二叉树转回树或森林

根作为第一棵树的根。沿右链走，根的右孩子是第二棵树的根，右孩子的右孩子是第三棵树的根，由此拆出森林各棵树。每棵树里，某结点的左孩子是它的第一个孩子，左孩子的右链是它的第 2、3 个孩子。

### 遍历的对应关系

| 树或森林的遍历 | 等价于转换后二叉树的 |
|---|---|
| 树的先根遍历 | 先序遍历 |
| 树的后根遍历 | 中序遍历 |
| 森林的先序遍历 | 先序遍历 |
| 森林的中序遍历 | 中序遍历 |

树没有"中根遍历"这个概念，因为孩子不分左右；森林也没有"后序遍历"。这个"没有"本身常考。

## 哈夫曼树

| 概念 | 定义 |
|---|---|
| 路径长度 | 从根到某结点的边数 |
| 结点的带权路径长度 | 权值乘从根到它的路径长度 |
| 树的带权路径长度 WPL | 所有叶子的带权路径长度之和 |
| 哈夫曼树 | 给定 n 个带权叶子，使 WPL 最小的二叉树 |
| 前缀编码 | 任一编码都不是另一编码的前缀 |
| 哈夫曼编码 | 由哈夫曼树生成的最优前缀编码 |
| 带权平均码长 | WPL 除以所有字符权值之和 |

### 构造算法

```
1. 把 n 个权值看作 n 棵单结点树，构成森林 F
2. 从 F 中选根权值最小的两棵树
3. 合并成一棵新树，新根权值等于两棵子树根权值之和
4. 从 F 中删去这两棵树，把新树加入 F
5. 重复 2 到 4，直到 F 只剩一棵树
```

几个必背结论：哈夫曼树共 `2n - 1` 个结点，n 个叶子加 n-1 个内部结点。树中没有度为 1 的结点。哈夫曼树不唯一（左右可互换、同权值结点可换位），但 WPL 唯一。哈夫曼编码也不唯一，但编码总长度唯一且最小。

### WPL 的两种算法

定义法最稳，写出每个叶子的权值乘深度再求和。

有个快得多的办法：WPL 等于构造过程中所有新产生的内部结点权值之和。因为每次合并产生的内部结点权值，正好等于其下所有叶子被多算的那一层，累加起来就是 WPL。这样完全不用画树。

例：权值 `{5, 7, 2, 13, 15, 19}`
```
排序：2, 5, 7, 13, 15, 19
合并 2+5   = 7    累加 7，森林 7,7,13,15,19
合并 7+7   = 14   累加 14，森林 13,14,15,19
合并 13+14 = 27   累加 27，森林 15,19,27
合并 15+19 = 34   累加 34，森林 27,34
合并 27+34 = 61   累加 61，森林 61
WPL = 7 + 14 + 27 + 34 + 61 = 143
```
定义法验证：叶子深度分别是 2 深 2、5 深 4、7 深 4、13 深 2、15 深 2、19 深 2，`2×4 + 5×4 + 7×3 + 13×2 + 15×2 + 19×2 = 8+20+21+26+30+38 = 143`，对上。

### 生成编码

从根出发，向左记 0、向右记 1，路径上的 0/1 序列就是编码。

接上面的树：
```
                    61
                  /    \
                27      34
               /  \    /  \
             13   14  15   19
                 /  \
                7    7
                   /  \
                  2    5
```
13 是 `00`，2 是 `0100`，5 是 `0101`，另一个 7 是 `011`，15 是 `10`，19 是 `11`。

验证前缀特性：`00`、`0100`、`0101`、`011`、`10`、`11`，没有哪个是另一个的前缀。

带权平均码长是 `143 / (2+5+7+13+15+19) = 143/61 ≈ 2.34`。

### 前缀特性怎么判断

把编码集合按字典序排好，若相邻两项中前一项是后一项的前缀，就不具前缀特性。

`{0, 10, 110, 1111}` 排序后逐对检查，0 不是 10 的前缀，10 不是 110 的前缀，110 不是 1111 的前缀，具有。

`{00, 10, 011, 110, 111}` 排序是 00, 011, 10, 110, 111，其中 10 是 110 的前缀，不具有。

## 考前十分钟

1. 结点数 = 边数 + 1 = 所有度之和 + 1。
2. 树的度是所有结点度的最大值。
3. `n₀ = 1 + n₂ + 2n₃ + 3n₄ + …`；二叉树 `n₀ = n₂ + 1`。
4. 只有度 0 和度 2 的二叉树，总结点 = 2k - 1。

7. 完全二叉树深度 `h = ⌊log₂n⌋ + 1`。

9. n 个结点的二叉链表有 n+1 个空指针。
10. 遍历辅助结构：先中后序用栈，层序用队列。

**C-1**
```c
/* 先序框架：空树 0；否则 (根值是否等于 x) 加左子树个数加右子树个数。
   时间 O(n)，空间 O(h)。 */
int countX(BTree t, ELEMType x) {
    if (t == NULL) return 0;
    return (t->data == x ? 1 : 0) + countX(t->left, x) + countX(t->right, x);
}
```

**C-2**
```c
/* 空树高 0，否则 max(左高, 右高) + 1。时间 O(n)，空间 O(h)。 */
int height(BTree t) {
    int lh, rh;
    if (t == NULL) return 0;
    lh = height(t->left);
    rh = height(t->right);
    return (lh > rh ? lh : rh) + 1;
}
```

**C-3**
```c
/* 度 1 就是只有一个孩子。空树 0，叶子 0，否则
   本结点是否度为 1 加左子树加右子树。 */
int countDeg1(BTree t) {
    if (t == NULL) return 0;
    if (t->left == NULL && t->right == NULL) return 0;
    int self = ((t->left == NULL) != (t->right == NULL)) ? 1 : 0;
    return self + countDeg1(t->left) + countDeg1(t->right);
}
```
`(a == NULL) != (b == NULL)` 是"恰好一个为空"的简洁写法。

**C-4**
```c
/* 后序框架：先递归处理左右子树，再交换本结点的左右指针。
   时间 O(n)，空间 O(h)。 */
void swapTree(BTree t) {
    BTree tmp;
    if (t == NULL) return;
    swapTree(t->left);
    swapTree(t->right);
    tmp = t->left;
    t->left = t->right;
    t->right = tmp;
}
```

int isSame(BTree a, BTree b) {
    if (a == NULL && b == NULL) return 1;
    if (a == NULL || b == NULL) return 0;

    return isSame(a->left, b->left) && isSame(a->right, b->right);
}

**C-8**
（1）给定 n 个带权叶子，构造出的 WPL 最小的二叉树叫哈夫曼树。
为什么最优：哈夫曼算法每次把权值最小的两棵树合并，使权值小的结点离根更远、权值大的离根更近，这正是"加权和最小"的贪心本质：让大权值乘以小路径长度。用交换论证可以证明任何其他形状的二叉树都无法得到更小的 WPL。

（2）哈夫曼编码是从根到叶子的路径标记。每个字符对应一个叶子结点，编码就是根到该叶子的 0/1 串。因为没有任何字符对应的结点是另一字符对应结点的祖先（叶子之间不可能互相包含路径），任何编码都不可能是另一编码的前缀。

（3）不唯一来自两处随机选择：每次合并时左右子树可互换，导致 0/1 对调；有相同权值的树时，选哪两棵合并可能有多种方案。但这些选择只改变树的形状和各自的 0/1 串，不改变每个叶子所处的深度。WPL 只依赖权值乘深度，所以恒定且最小。

**C-9**
（1）三种存储结构：
双亲表示法用数组存结点，每结点含 data 和 parent（父结点下标）。找父 O(1)，找孩子要遍历全表 O(n)。
孩子表示法用数组加每结点的孩子链表。找孩子快，找父要遍历所有孩子链。
孩子兄弟表示法每结点含 data、firstChild（第一个孩子）、nextSibling（下一个兄弟）。找孩子找兄弟都是 O(1)，且能把树转为二叉树，复用二叉树的全部算法。
